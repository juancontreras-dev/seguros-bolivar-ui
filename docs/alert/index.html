🔔 Alert & Toast Component

Componentes de alerta y notificaciones tipo toast. Soporta múltiples variantes (success, info, warning, error), tipos (inline, toast) y posiciones configurables.

Variantes (Success, Info, Warning, Error)

✅ Success

¡Operación exitosa!
Tu información ha sido guardada correctamente.

ℹ️ Info

Información importante
Recuerda revisar tu correo para confirmar la operación.

⚠️ Warning

Advertencia
Esta acción no se puede deshacer. Por favor, confirma antes de continuar.

❌ Error

Error en la operación
No se pudo completar la operación. Por favor, intenta nuevamente.

Tamaños (Small, Medium, Large)

📉 Small

Alerta pequeña compacta

📊 Medium (Default)

Tamaño estándar
Este es el tamaño por defecto de las alertas.

📈 Large

Alerta grande destacada
Este tamaño es ideal para información muy importante que requiere atención inmediata del usuario.

Opciones de Visualización

🚫 Sin Icono

Sin icono decorativo
Esta alerta no incluye icono al inicio.

🔒 Sin Botón Cerrar

Alerta persistente
Esta alerta no puede ser cerrada por el usuario.

📝 Solo Mensaje

Mensaje simple sin título.

🎨 Con Fondo de Color

Alerta con fondo
Esta alerta usa un fondo de color para mayor visibilidad.
