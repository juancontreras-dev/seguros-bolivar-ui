Tabs

Componente de pestañas de navegación (tabs) para organizar contenido en secciones. Compatible con todas las marcas del design system.

Ejemplo de uso HTML 
<!-- Tabs con Web Component -->
<sb-ui-tabs active="tab1">
  <sb-ui-tab slot="tab" tab-id="tab1">Pestaña 1</sb-ui-tab>
  <sb-ui-tab slot="tab" tab-id="tab2">Pestaña 2</sb-ui-tab>
  
  <div slot="panel" data-tab="tab1">
    Contenido de Pestaña 1
  </div>
  <div slot="panel" data-tab="tab2">
    Contenido de Pestaña 2
  </div>
</sb-ui-tabs>
