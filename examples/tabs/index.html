Tabs (Pestañas)

Las tabs (pestañas) son un elemento común en el diseño de interfaz de usuario (UI) y experiencia de usuario (UX) que se utilizan para organizar y presentar contenido de manera estructurada y accesible. Permiten a los usuarios cambiar entre diferentes secciones o categorías de contenido sin tener que abandonar la página actual.

Requisitos previos
HTML 
<!-- 1. Atributos obligatorios en <html> para activar tokens del tema -->
<html data-brand="seguros-bolivar" data-theme="light">

<!-- 2. Bundle CSS del Design System (incluye fuentes e iconos) -->
<link rel="stylesheet" href="https://unpkg.com/@seguros-bolivar/ui-bundle@latest/dist/sb-ui-seguros-bolivar-light.min.css">

<!-- Nota: El bundle usa @layer para organizar la cascada CSS.             -->
<!-- Si escribes CSS propio SIN @layer, tendra mayor prioridad que el DS. -->
<!-- Para evitar conflictos, pon tu CSS en una capa posterior:             -->
<!-- @layer app { .mi-clase { ... } }                                     -->

Variante Track (Solo Texto)

Linea inferior verde que indica la pestana activa. Funciona unicamente con el bundle CSS, sin dependencias externas.

Track Tabs

Ejemplo de uso
HTML 
<!-- Tabs Track: solo requiere el bundle CSS del Design System -->
<div class="sb-ui-tabs sb-ui-tabs--track" role="tablist">
  <button class="sb-ui-tabs__item sb-ui-tabs__item--active" role="tab" aria-selected="true">
    <span class="sb-ui-tabs__title">General</span>
    <span class="sb-ui-tabs__description">Informacion general</span>
  </button>
  <button class="sb-ui-tabs__item" role="tab" aria-selected="false">
    <span class="sb-ui-tabs__title">Contacto</span>
    <span class="sb-ui-tabs__description">Datos de contacto</span>
  </button>
</div>

Estado Loading

Las tabs en estado de carga tienen opacidad reducida y no responden a clicks. Util mientras se carga contenido asincrono.

Track Tabs - Loading

Ejemplo de uso
HTML 
<!-- Tabs en estado loading (opacidad reducida, no clickeable) -->
<div class="sb-ui-tabs sb-ui-tabs--track sb-ui-tabs--loading" role="tablist">
  <button class="sb-ui-tabs__item sb-ui-tabs__item--active" role="tab" aria-selected="true">
    <span class="sb-ui-tabs__title">General</span>
    <span class="sb-ui-tabs__description">Cargando...</span>
  </button>
  <button class="sb-ui-tabs__item" role="tab" aria-selected="false">
    <span class="sb-ui-tabs__title">Contacto</span>
    <span class="sb-ui-tabs__description">Datos de contacto</span>
  </button>
</div>

<!-- Funciona con todas las variantes: --track, --button, --folder -->
