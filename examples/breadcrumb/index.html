Breadcrumb

Componente de navegacion jerarquica que muestra la ubicacion actual del usuario dentro de la estructura del sitio. Los breadcrumbs ayudan a los usuarios a orientarse y navegar eficientemente.

Breadcrumb con icono inicial

Breadcrumb con icono solo en el primer elemento, los siguientes elementos son solo texto.

  1. Option
  2. Option
  3. Option
Ejemplo de uso
HTML 
<nav class="sb-ui-breadcrumb" aria-label="breadcrumb">
  <ol class="sb-ui-breadcrumb__list">
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">
        <i class="fa-solid fa-house sb-ui-breadcrumb__icon" aria-hidden="true"></i>
        Option
      </a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Option</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <span class="sb-ui-breadcrumb__current" aria-current="page">Option</span>
    </li>
  </ol>
</nav>
