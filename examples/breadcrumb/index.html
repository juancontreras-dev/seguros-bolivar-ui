Breadcrumb

Componente de navegacion jerarquica que muestra la ubicacion actual del usuario dentro de la estructura del sitio. Los breadcrumbs ayudan a los usuarios a orientarse y navegar eficientemente.

Requisitos previos
HTML 
<!-- 1. Atributos obligatorios en <html> para activar tokens del tema -->
<html data-brand="seguros-bolivar" data-theme="light">

<!-- 2. Bundle CSS del Design System (incluye fuentes e iconos) -->
<link rel="stylesheet" href="https://unpkg.com/@seguros-bolivar/ui-bundle@latest/dist/sb-ui-seguros-bolivar-light.min.css">

<!-- Nota: El bundle usa @layer para organizar la cascada CSS.             -->
<!-- Si escribes CSS propio SIN @layer, tendra mayor prioridad que el DS. -->
<!-- Para evitar conflictos, pon tu CSS en una capa posterior:             -->
<!-- @layer app { .mi-clase { ... } }                                     -->

Solo Texto (sin dependencias externas)

Breadcrumb basico sin iconos. Funciona unicamente con el bundle CSS, sin necesidad de librerias externas.

  1. Inicio
  2. Productos
  3. Seguros
Ejemplo de uso
HTML 
<!-- Breadcrumb: solo requiere el bundle CSS del Design System -->
<nav class="sb-ui-breadcrumb" aria-label="breadcrumb">
  <ol class="sb-ui-breadcrumb__list">
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Inicio</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Productos</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <span class="sb-ui-breadcrumb__current" aria-current="page">Seguros</span>
    </li>
  </ol>
</nav>

Estado Collapsed (colapsado)

Fuerza el colapso del breadcrumb mostrando solo el primer y ultimo elemento, con puntos suspensivos entre ellos. Util cuando la ruta es muy larga y el espacio es limitado.

  1. Inicio
  2. Productos
  3. Seguros
  4. Vida
  5. Detalle del plan
Ejemplo de uso
HTML 
<!-- Breadcrumb colapsado: solo muestra primero y ultimo -->
<nav class="sb-ui-breadcrumb sb-ui-breadcrumb--collapsed" aria-label="breadcrumb">
  <ol class="sb-ui-breadcrumb__list">
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">
        <i class="fa-solid fa-house sb-ui-breadcrumb__icon" aria-hidden="true"></i>
        Inicio
      </a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Productos</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Seguros</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <span class="sb-ui-breadcrumb__current" aria-current="page">Detalle</span>
    </li>
  </ol>
</nav>

Estado Loading (cargando)

Muestra el breadcrumb en estado de carga con opacidad reducida y puntero de espera. Los links no son clickeables.

  1. Inicio
  2. Productos
  3. Cargando...
Ejemplo de uso
HTML 
<!-- Breadcrumb en estado loading -->
<nav class="sb-ui-breadcrumb sb-ui-breadcrumb--loading" aria-label="breadcrumb">
  <ol class="sb-ui-breadcrumb__list">
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Inicio</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Productos</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <span class="sb-ui-breadcrumb__current" aria-current="page">Cargando...</span>
    </li>
  </ol>
</nav>

Sin colapso en mobile (no-collapse)

Por defecto, breadcrumbs con muchos items se colapsan automaticamente en pantallas menores a 640px. Usa sb-ui-breadcrumb--no-collapse para evitar este comportamiento y mostrar siempre todos los items.

  1. Inicio
  2. Productos
  3. Seguros
  4. Vida
  5. Plan familiar
Ejemplo de uso
HTML 
<!-- Evitar colapso automatico en mobile -->
<nav class="sb-ui-breadcrumb sb-ui-breadcrumb--no-collapse" aria-label="breadcrumb">
  <ol class="sb-ui-breadcrumb__list">
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Inicio</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Productos</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Seguros</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <span class="sb-ui-breadcrumb__current" aria-current="page">Plan familiar</span>
    </li>
  </ol>
</nav>
