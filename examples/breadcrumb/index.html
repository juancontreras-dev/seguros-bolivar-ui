Breadcrumb

Componente de navegación jerárquica (breadcrumb) para indicar la ubicación actual dentro de la estructura del sitio. Compatible con todas las marcas del design system.

Ejemplos

Breadcrumb Básico

  1. Inicio
  2. Productos
  3. Seguros de Vida

Breadcrumb con Iconos

  1. Inicio
  2. Documentos
  3. Archivo.pdf
Ejemplo de uso HTML 
<!-- Breadcrumb básico -->
<nav class="sb-ui-breadcrumb">
  <ol class="sb-ui-breadcrumb__list">
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Inicio</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Productos</a>
    </li>
    <li class="sb-ui-breadcrumb__item sb-ui-breadcrumb__item--active">
      <span class="sb-ui-breadcrumb__text">Actual</span>
    </li>
  </ol>
</nav>
