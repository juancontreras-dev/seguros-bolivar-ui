🧭 Breadcrumb Component

Componente de navegación breadcrumb con separadores personalizables. Usa semántica HTML5 con <nav> y <ol> para máxima accesibilidad.

Breadcrumb Básico

Navegación estándar con links verdes (color primario) y página actual en gris.

Ejemplo - Directorio Médico

  1. Directorio médico
  2. Medicina general
  3. Perfil médico

Ejemplo - Navegación Profunda

  1. Inicio
  2. Seguros
  3. Vida
  4. Cotizar
  5. Detalles

Breadcrumb Colapsado

En móvil, el breadcrumb se colapsa automáticamente mostrando solo el primero y el último elemento.

Auto-collapse en móvil (<640px)

  1. Inicio
  2. Nivel 2
  3. Nivel 3
  4. Nivel 4
  5. Nivel 5

💡 Reduce el ancho de la ventana a menos de 640px para ver el efecto de colapso.

Collapse forzado (clase --collapsed)

  1. Inicio
  2. Nivel 2
  3. Nivel 3
  4. Página actual

Estados

Diferentes estados del componente breadcrumb.

Loading

  1. Inicio
  2. Categoría
  3. Página

Solo 2 niveles

  1. Inicio
  2. Página actual

Sin collapse en móvil

  1. Inicio
  2. Nivel 2
  3. Nivel 3
  4. Página

💡 Usa sb-ui-breadcrumb--no-collapse para mantener todos los items visibles en móvil.

Código HTML

<nav class="sb-ui-breadcrumb" aria-label="Breadcrumb"> <ol class="sb-ui-breadcrumb__list"> <li class="sb-ui-breadcrumb__item"> <a href="#" class="sb-ui-breadcrumb__link">Directorio médico</a> </li> <li class="sb-ui-breadcrumb__item"> <a href="#" class="sb-ui-breadcrumb__link">Medicina general</a> </li> <li class="sb-ui-breadcrumb__item"> <span class="sb-ui-breadcrumb__current" aria-current="page"> Perfil médico </span> </li> </ol> </nav>

Características

✅ Accesible

Usa aria-label y aria-current para lectores de pantalla.

📱 Responsive

Se colapsa automáticamente en móvil (<640px) mostrando primero...último.

🎨 Personalizable

Variables CSS para colores, separadores y espaciado.

♿ Accesibilidad

Soporte para prefers-contrast y prefers-reduced-motion.
