Breadcrumb

Componente de navegación jerárquica que muestra la ubicación actual del usuario dentro de la estructura del sitio. Los breadcrumbs ayudan a los usuarios a orientarse y navegar eficientemente.

Variantes

El breadcrumb soporta dos configuraciones principales según Figma: Con icono izquierdo (Left Icon: True) y Sin icono izquierdo (Left Icon: False). Iconos de 16px × 16px según especificación.

Con icono izquierdo (Left Icon: True)

  1. Inicio
  2. Productos
  3. Seguros de Vida

Sin icono izquierdo (Left Icon: False)

  1. Inicio
  2. Productos
  3. Seguros de Vida
Ejemplo de uso
HTML 
<!-- Con icono izquierdo -->
<nav class="sb-ui-breadcrumb" aria-label="breadcrumb">
  <ol class="sb-ui-breadcrumb__list">
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">
        <i class="fa-solid fa-home sb-ui-breadcrumb__icon"></i>
        Inicio
      </a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <a href="#" class="sb-ui-breadcrumb__link">Productos</a>
    </li>
    <li class="sb-ui-breadcrumb__item">
      <span class="sb-ui-breadcrumb__current" aria-current="page">Actual</span>
    </li>
  </ol>
</nav>

Estados Interactivos

Según Figma, los breadcrumb items tienen cuatro estados visuales: Default, Hover, Focused, y Active (página actual).

Default

  1. Inicio

Hover (pasa el mouse)

  1. Inicio

Focused (presiona Tab)

  1. Inicio

Active (página actual)

  1. Página Actual

HTML 
<!-- Active state (página actual) -->
<li class="sb-ui-breadcrumb__item">
  <span class="sb-ui-breadcrumb__current" aria-current="page">Actual</span>
</li>

Buenas Prácticas

Según las especificaciones de Figma, estas son las mejores prácticas para usar breadcrumbs eficientemente.

✓

Sí hacer

Úselo para sitios web grandes y productos complejos que tienen páginas organizadas jerárquicamente, de modo que los usuarios que llegan a la página puedan saber rápidamente dónde están.

  1. Inicio
  2. Estándares mínimos 0312
  3. Repositorio de certificaciones
✓

Ubicación correcta

Ubicar el breadcrumbs en la esquina superior izquierda de la página, bajo el título de esta.

Título de la Página
  1. Inicio
  2. Sección
  3. Actual
✗

No hacer - Herramienta secundaria

Tu navegación de breadcrumbs es una herramienta secundaria a tu barra de navegación principal, por lo que no debe ser demasiado grande o prominente en la página.

  1. Inicio
  2. Actual
✗

No hacer - Confusión

Otra ubicación podría confundir la función del breadcrumbs.

  1. Inicio
  2. Actual
Título de la Página

Estado Colapsado para Móviles

En pantallas pequeñas (menores a 640px), el breadcrumb automáticamente colapsa mostrando solo el primer y último nivel con "..." en medio. Esto mantiene la funcionalidad sin ocupar demasiado espacio.

Vista móvil (< 640px)

  1. Inicio
  2. Nivel 2
  3. Nivel 3
  4. Repositorio de certificaciones

Los niveles intermedios se ocultan automáticamente, manteniendo solo inicio y página actual.

Ejemplo de uso
HTML 
<!-- Colapsado manual con clase -->
<nav class="sb-ui-breadcrumb sb-ui-breadcrumb--collapsed" aria-label="breadcrumb">
  <ol class="sb-ui-breadcrumb__list">
    <!-- Solo se muestran primer y último item -->
  </ol>
</nav>

<!-- Auto-colapsa en móvil (< 640px) -->
<nav class="sb-ui-breadcrumb" aria-label="breadcrumb">
  <ol class="sb-ui-breadcrumb__list">
    <!-- Todos los items, se ocultan automáticamente en móvil -->
  </ol>
</nav>
