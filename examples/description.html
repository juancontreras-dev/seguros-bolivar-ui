¿Qué es Seguros Bolívar UI?

Seguros Bolívar UI es una librería transversal de componentes frontend diseñada para estandarizar, acelerar y gobernar la construcción de interfaces digitales de la compañía. Es el lenguaje visual y técnico común de todos los productos digitales de Seguros Bolívar.

La librería ofrece dos tipos de componentes:

  • Componentes HTML + CSS: Clases CSS reutilizables con nomenclatura BEM, ideales para cualquier proyecto sin dependencias de JavaScript.
  • Web Components: Elementos personalizados con funcionalidad interactiva encapsulada (calendarios, datepickers, etc.) que funcionan en cualquier framework.

Además incluye tokens de diseño y un sistema de temas (theming) configurable. Es independiente de framework (no está atada a Angular, React u otro), lo que la convierte en la base ideal para construir frontends corporativos consistentes.

La librería es multimarca: soporta aliados actuales (Seguros Bolívar, Davivienda, Jelpit, Cien Cuadras y Doctor Aki) y futuros, permitiendo cambios globales desde un solo lugar mediante temas y tokens. Además, es escalable en el tiempo sin necesidad de actualización de versiones obligatorias.

Características Técnicas

Botones, inputs, selects, modales, calendarios, tablas y más. Todos probados y optimizados para producción.

Multi-Marca

Soporte nativo para Seguros Bolívar, Davivienda, Jelpit, Cien Cuadras, Doctor Aki y White Label.

Framework Agnostic

No está atada a Angular, React u otro. Compatible con cualquier tecnología frontend.

Ligero y Rápido

~25KB CSS + ~16KB JS (gzipped). Sin dependencias externas pesadas.

Accesible (WCAG 2.1)

Componentes diseñados siguiendo las mejores prácticas de accesibilidad web.

Comenzar es Fácil

HTML Snippet 
<!-- Solo agrega esto en tu HTML -->
<link rel="stylesheet" href="https://unpkg.com/@seguros-bolivar/ui-bundle@latest/dist/sb-ui-seguros-bolivar-light.min.css">
<script type="module" src="https://unpkg.com/@seguros-bolivar/ui-bundle@latest/dist/sb-ui-components.min.js"></script>

<!-- ¡Y empieza a usar los componentes! -->
<button class="sb-ui-button sb-ui-button--primary sb-ui-button--fill">¡Hola Mundo!</button>
