Calendar

Componente de calendario para selección de fechas con tres variantes principales: Single (selección única), Range (rango de fechas) y Multiple (múltiples fechas independientes). Compatible con todas las marcas del design system.

Selección de Fecha Única

Permite al usuario seleccionar una sola fecha. Ideal para campos de formulario como "Fecha de Nacimiento" o "Fecha de Cita".

1. Default

Calendario simple con un día seleccionado (15 de Marzo)

Ejemplo de uso HTML 
<!-- Single Date Picker -->
<div class="sb-ui-calendar" data-variant="single">
  <div class="sb-ui-calendar__header">
    <button class="sb-ui-calendar__nav-button">◀</button>
    <div class="sb-ui-calendar__month-year">Marzo - 2024</div>
    <button class="sb-ui-calendar__nav-button">▶</button>
  </div>
  
  <div class="sb-ui-calendar__weekdays">
    <div class="sb-ui-calendar__weekday">Do</div>
    <!-- ... más días ... -->
  </div>
  
  <div class="sb-ui-calendar__days">
    <button class="sb-ui-calendar__day sb-ui-calendar__day--selected">15</button>
    <!-- ... más días ... -->
  </div>
  
  <div class="sb-ui-calendar__footer">
    <button class="sb-ui-button sb-ui-button--secondary">Cancelar</button>
    <button class="sb-ui-button sb-ui-button--primary">Aceptar</button>
  </div>
</div>

Ejemplo de uso HTML 
<!-- Range Date Picker (dos meses) -->
<div class="sb-ui-calendar sb-ui-calendar--double" data-variant="range">
  <!-- Mes 1 -->
  <div class="sb-ui-calendar__month">
    <!-- ... Header y días ... -->
    <button class="sb-ui-calendar__day sb-ui-calendar__day--range-start">15</button>
    <button class="sb-ui-calendar__day sb-ui-calendar__day--in-range">16</button>
    <!-- ... más días en rango ... -->
  </div>
  
  <!-- Mes 2 -->
  <div class="sb-ui-calendar__month">
    <!-- ... Header y días ... -->
    <button class="sb-ui-calendar__day sb-ui-calendar__day--in-range">1</button>
    <button class="sb-ui-calendar__day sb-ui-calendar__day--range-end">8</button>
  </div>
</div>
