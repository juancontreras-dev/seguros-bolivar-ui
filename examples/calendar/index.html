Calendario

Componente de calendario y selector de fechas. Incluye DatePicker (input + calendario desplegable) con variantes single, range y multiple, tamaños small/medium/large y soporte para todas las marcas del design system.

DatePicker con input

Campo de texto con ícono de calendario. Al hacer clic en el input o en el ícono se abre el calendario. La fecha seleccionada se muestra en el input.

Fecha única

Input con placeholder. Clic en el campo o en el ícono para abrir.

Con valor inicial

Input con fecha ya seleccionada (15/03/2024).

Tamaño small

DatePicker compacto.

Selección de fecha única (Single)

Permite seleccionar una sola fecha. Ideal para formularios como "Fecha de Nacimiento" o "Fecha de Cita". Todos incluyen input.

Default

Input + calendario. Clic en el campo o ícono para abrir.

Con valor inicial

Input con fecha ya seleccionada (15/03/2024).

Selección de rango (Range)

Permite seleccionar un rango de fechas (inicio y fin). Útil para reservas, reportes, filtros. Incluye input donde se muestra el rango.

Rango con input

Input + calendario de rango. Clic en el campo o ícono para abrir.

Selección múltiple (Multiple)

Permite seleccionar múltiples fechas. Útil para agendar varias citas o días laborables. Incluye input donde se muestran las fechas.

Múltiples fechas con input

Input + calendario. Selecciona varias fechas; se muestran en el campo.

Tamaños

El datepicker soporta 3 tamaños: small, medium (default) y large. Todos con input visible.

Small

Input y botón compactos.

Medium (default)

Tamaño estándar.

Large

Input y botón más grandes.

Uso del componente

HTML básico (todos con input)

Ejemplo de uso HTML 
<!-- Single -->
<sb-ui-datepicker variant="single" placeholder="Seleccionar fecha" label="Fecha"></sb-ui-datepicker>

<!-- Range -->
<sb-ui-datepicker variant="range" placeholder="DD/MM/YYYY - DD/MM/YYYY" label="Período"></sb-ui-datepicker>

<!-- Multiple -->
<sb-ui-datepicker variant="multiple" placeholder="Seleccionar fechas" label="Días"></sb-ui-datepicker>

<!-- Tamaños -->
<sb-ui-datepicker variant="single" size="small" label="Small"></sb-ui-datepicker>
