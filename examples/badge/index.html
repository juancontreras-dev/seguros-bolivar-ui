Badge

Indicadores visuales de feedback que comunican estados (error, warning, info, success). Disponibles en 3 tamaños con soporte para texto, iconos o ambos.

Error (Rojo)

Badge con fondo rojo (#dc3545) para indicar errores, notificaciones críticas o alertas que requieren atención inmediata.

8 Large (20px) + Texto
Large (20px) + Icono
8 Medium (16px) + Texto
Medium (16px) + Icono
8 Small (12px) + Texto
Small (12px) + Icono

Ejemplo de uso

HTML 
<!-- Badge Error - Large con texto -->
<span class="sb-ui-badge sb-ui-badge--error sb-ui-badge--large">8</span>

<!-- Badge Error - Large con icono -->
<span class="sb-ui-badge sb-ui-badge--error sb-ui-badge--large sb-ui-badge--icon-only">
  <i class="fa-solid fa-exclamation"></i>
</span>
