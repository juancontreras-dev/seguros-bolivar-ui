Grid (Sistema de 12 Columnas)

Sistema de grid de 12 columnas basado en CSS Grid moderno. Mobile-first y responsive. Compatible con gutters y column utilities. Permite crear layouts flexibles sin necesidad de código JavaScript. Define el número de columnas según el breakpoint.

Grid Responsive (Mobile → Tablet → Desktop)

Grids que cambian su número de columnas según el breakpoint. Mobile-first: comienza con 1 columna y expande en pantallas grandes.

1
2
3
4
5
6

Redimensiona: Mobile 1 col → Tablet 2 cols → Desktop 3 cols

Ejemplo de uso HTML 
<!-- Mobile: 1 col, Tablet: 2 cols, Desktop: 3 cols -->
<div style="
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
">
  <div>Item 1</div>
  <div>Item 2</div>
</div>

<!-- Media Queries -->
<style>
  @media (min-width: 576px) {
    .responsive-grid {
      grid-template-columns: repeat(2, 1fr);
    }
  }
  @media (min-width: 768px) {
    .responsive-grid {
      grid-template-columns: repeat(3, 1fr);
    }
  }
</style>
