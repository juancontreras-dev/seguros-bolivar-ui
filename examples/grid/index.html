Grid (Sistema de 12 Columnas)

Sistema de grid de 12 columnas basado en CSS Grid moderno. Mobile-first y responsive. Compatible con gutters y column utilities. Permite crear layouts flexibles sin necesidad de código JavaScript. Define el número de columnas según el breakpoint.

Grid Responsive (Mobile → Tablet → Desktop)

Agrega una clase de columna por cada breakpoint que necesites, todas en el mismo elemento. Sin prefijo aplica en móvil; cada prefijo se activa desde ese ancho hacia arriba. Redimensiona la ventana para ver los demos en acción.

Breakpoint actual: xs (<576px)
Breakpoint Desde Clase
xs — móvil siempre col-{1 a 12}
sm ≥ 576px col-sm-{1 a 12}
md — tablet ≥ 768px col-md-{1 a 12}
lg — desktop ≥ 992px col-lg-{1 a 12}
xl ≥ 1200px col-xl-{1 a 12}
xxl ≥ 1400px col-xxl-{1 a 12}
