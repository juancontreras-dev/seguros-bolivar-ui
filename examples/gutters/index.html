Gutters (Espaciado)

Utilities CSS para controlar el espaciado entre elementos de un grid mediante la propiedad gap. Compatible con CSS Grid y Flexbox. Incluye escala de 6 niveles (0-5) y variantes responsive para todos los breakpoints. Usa propiedades lógicas para soporte RTL/LTR automático.

Escala de Spacing

El sistema de gutters usa una escala consistente de 6 niveles (0-5) basada en múltiplos de 4px:

Nivel Variable CSS Valor (rem) Valor (px) Uso Recomendado
0 --sb-ui-gap-0 0 0px Sin espaciado
1 --sb-ui-gap-1 0.25rem 4px Espaciado muy compacto
2 --sb-ui-gap-2 0.5rem 8px Espaciado compacto
3 --sb-ui-gap-3 1rem 16px Espaciado estándar
4 --sb-ui-gap-4 1.5rem 24px Espaciado cómodo (default)
5 --sb-ui-gap-5 3rem 48px Espaciado amplio

Gap en Ambas Direcciones (.sb-ui-gap-*)

Aplica espaciado uniforme entre filas y columnas usando la propiedad gap.

Ejemplo de uso HTML 
<!-- Gap de 16px (1rem) en ambas direcciones -->
<div class="sb-ui-grid sb-ui-gap-3">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

<!-- Gap de 48px (3rem) en ambas direcciones -->
<div class="sb-ui-grid sb-ui-gap-5">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

Gutters Responsive

Combina clases de gutters con sufijos de breakpoint para espaciado responsive. Mobile-first: comienza con gap pequeño y aumenta en pantallas grandes.

1
2
3
4

Responsive: 4px mobile → 16px tablet (md) → 48px desktop (lg)

Ejemplo de uso HTML 
<!-- Mobile: 4px, Tablet (md): 16px, Desktop (lg): 48px -->
<div class="sb-ui-grid sb-ui-gap-1 sb-ui-gap-md-3 sb-ui-gap-lg-5">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

<!-- Breakpoints disponibles: sm (576px), md (768px), lg (992px), xl (1200px), xxl (1400px) -->
