Containers (Contenedores)

Contenedores responsive con ancho máximo controlado. Centrados automáticamente con padding lateral. 3 variantes: responsive, fluid y breakpoint-specific. Garantizan que el contenido sea legible en todas las pantallas.

Container Responsive (Default)

Contenedor con ancho máximo que se adapta a cada breakpoint. Centrado automáticamente con padding horizontal. Comienza al 100% en móvil y se limita progresivamente en pantallas más grandes.

sb-ui-container
Responsive automático — se limita según el breakpoint
100% en móvil, centra y limita en pantallas grandes
Comportamiento: Se expande hasta el max-width especificado, luego se limita y centra. Incluye padding horizontal para separación del borde de pantalla.
Ejemplo de uso
HTML 
<div class="sb-ui-container">
  <h1>Título principal</h1>
  <p>Contenido que se adapta automáticamente...</p>
</div>

<!-- Max-widths automáticos por breakpoint: -->
<!-- sm (576px):  max-width 540px  -->
<!-- md (768px):  max-width 720px  -->
<!-- lg (992px):  max-width 960px  -->
<!-- xl (1200px): max-width 1140px -->
<!-- xxl(1400px): max-width 1320px -->

Container Fluid (100% Width)

Contenedor que ocupa el 100% del ancho disponible. Mantiene padding horizontal para separación del borde. Útil para secciones full-width que necesitan mantener márgenes laterales.

sb-ui-container-fluid
Siempre 100% del ancho disponible
Sin max-width en cualquier pantalla
Caso de uso: Secciones de color completo (headers, footers) o galerías que ocupan todo el ancho.
Ejemplo de uso
HTML 
<div class="sb-ui-container-fluid">
  <!-- Contenido 100% ancho -->
  <section>Full width content</section>
</div>

<!-- .sb-ui-container-fluid ocupa siempre el 100% -->
<!-- Solo mantiene padding-inline para separación lateral -->

Max-widths por Breakpoint

Referencia completa de los max-widths aplicados en cada breakpoint. Los contenedores se expanden hasta estos límites.

Breakpoint Min-width Clase desde este punto Max-width
XS 0 px sb-ui-container fluid (100%)
SM 576 px sb-ui-container-sm 540 px
MD 768 px sb-ui-container-md 720 px
LG 992 px sb-ui-container-lg 960 px
XL 1200 px sb-ui-container-xl 1140 px
XXL 1400 px sb-ui-container-xxl 1320 px
Padding: todos los containers usan el mismo padding responsive: clamp(1rem, 0.5rem + 2vw, 1.5rem). Se ajusta automáticamente según el ancho de pantalla, no hace falta configurarlo.

Container desde un breakpoint específico

Estas clases son fluid (100%) hasta el breakpoint que indica su nombre. Desde ese punto aplican max-width y se centran, igual que sb-ui-container. El slider de abajo simula ese comportamiento: mueve el ancho y observa cómo cada barra se limita en un punto diferente.

Cómo funciona: cada container es fluid hasta su breakpoint de activación. Una vez que el viewport supera ese punto, se limita al max-width correspondiente y se centra. Verde = fluid, gris = limitado. En producción esto sucede automáticamente según el ancho del viewport.
Ejemplo de uso
HTML 
<!-- Fluid hasta el breakpoint indicado, luego se limita -->
<div class="sb-ui-container-md">
  <!-- fluid hasta 768px → max 720px desde MD -->
</div>

<div class="sb-ui-container-lg">
  <!-- fluid hasta 992px → max 960px desde LG -->
</div>

<div class="sb-ui-container-xl">
  <!-- fluid hasta 1200px → max 1140px desde XL -->
</div>

<!-- También disponibles: -->
<!-- .sb-ui-container-sm   → fluid hasta 576px -->
<!-- .sb-ui-container-xxl  → fluid hasta 1400px -->
