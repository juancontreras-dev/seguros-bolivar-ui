Toggle

Componente de interruptor (switch) para habilitar/deshabilitar opciones con estados completos (default, hover, focus, disabled), tamaños (small, medium, large) y variantes para configuraciones y casos de uso reales. Compatible con todas las marcas del design system.

Estados Básicos

1. Default (Off)

2. Default (On)

3. Hover

Pasa el mouse sobre el toggle

4. Focus

Click o usa Tab para ver el focus

5. Disabled (Off)

6. Disabled (On)

Ejemplo de uso HTML 
<!-- Toggle Off -->
<label class="sb-ui-toggle">
  <input type="checkbox" class="sb-ui-toggle-input" />
  <span class="sb-ui-toggle-slider"></span>
  <span class="sb-ui-toggle-label">Toggle desactivado</span>
</label>

<!-- Toggle On -->
<label class="sb-ui-toggle">
  <input type="checkbox" class="sb-ui-toggle-input" checked />
  <span class="sb-ui-toggle-slider"></span>
  <span class="sb-ui-toggle-label">Toggle activado</span>
</label>

<!-- Toggle Disabled -->
<label class="sb-ui-toggle">
  <input type="checkbox" class="sb-ui-toggle-input" disabled />
  <span class="sb-ui-toggle-slider"></span>
  <span class="sb-ui-toggle-label">Disabled</span>
</label>
