Botón secundario

Componente botón secundario con todas sus variantes (FILL, STROKE, TEXT), estados interactivos (default, hover, loading, disabled) y posiciones de iconos (left, right, only). Compatible con todas las marcas del design system.

Variante Fill

Estado Icon Left Icon Right Default Icon Only
Default
Loading
Disabled
Ejemplo de uso HTML 
<!-- Estado Default -->
<button class="sb-ui-button sb-ui-button--secondary sb-ui-button--fill">Action</button>

<!-- Estado Loading -->
<button class="sb-ui-button sb-ui-button--secondary sb-ui-button--fill sb-ui-button--loading">Action</button>

<!-- Estado Disabled -->
<button class="sb-ui-button sb-ui-button--secondary sb-ui-button--fill sb-ui-button--disabled">Action</button>
