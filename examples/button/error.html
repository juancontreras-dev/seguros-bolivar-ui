Botón de error

Componente botón de error con todas sus variantes (FILL, STROKE, TEXT), estados interactivos (default, hover, loading, disabled) y posiciones de iconos (left, right, only). Compatible con todas las marcas del design system.

Estado Icon Left Icon Right Default (Sin icono) Icon Only

<!-- Estado Default -->

<button class="sb-ui-button sb-ui-button--error sb-ui-button--fill sb-ui-button--loading">Action</button>

<!-- Estado Disabled -->
