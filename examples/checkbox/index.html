5. Estado Focus

Halo verde claro (#E5F4EE) aparece cuando el checkbox recibe foco por teclado (Tab)

Focus en Unchecked

Presiona Tab para ver el halo de focus

Focus en Checked

El halo de focus también aparece en checkboxes marcados

Accesibilidad

El halo de focus cumple con WCAG 2.1 AA para indicadores visuales

6. Estado Disabled

Checkbox y texto en color gris (#9B9B9B) para indicar que no están disponibles

Disabled Unchecked

Box y texto en gris, no responde a interacciones

Disabled Checked

Muestra selección pero no permite cambios

Tamaños Disabled

El estado disabled funciona en todos los tamaños

7. Estado Error

Border y texto en rojo (#DC3545) para indicar validación fallida

Error en Validación

Indica que el campo requiere atención del usuario

Error + Hover

Halo rojizo aparece en hover/pressed manteniendo el color de error

Error + Disabled

Estado disabled tiene prioridad sobre error visual

10. Código de Ejemplo

HTML Básico

<!-- Checkbox normal -->
<label class="sb-ui-checkbox">
  <input type="checkbox" class="sb-ui-checkbox__input" />
  <span class="sb-ui-checkbox__box"></span>
  <span class="sb-ui-checkbox__label">Option text</span>
</label>

<!-- Checkbox con error (validación fallida) -->
<label class="sb-ui-checkbox sb-ui-checkbox--error">
  <input type="checkbox" class="sb-ui-checkbox__input" />
  <span class="sb-ui-checkbox__box"></span>
  <span class="sb-ui-checkbox__label">Campo requerido</span>
</label>

Clases Disponibles

/* CLASE BASE */
sb-ui-checkbox (clase única, sin variantes)

/* ESTADOS */
sb-ui-checkbox--error (validación fallida)
sb-ui-checkbox--loading (operación async)
sb-ui-checkbox--readonly (solo lectura)

/* TAMAÑOS */
sb-ui-checkbox--small (16x16px)
sb-ui-checkbox--medium (20x20px - default)
sb-ui-checkbox--large (24x24px)

/* MODIFIERS */
