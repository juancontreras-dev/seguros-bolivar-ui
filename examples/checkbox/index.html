Checkbox

Componente de selección múltiple con estados completos (default, hover, focus, disabled, indeterminate, error), tamaños (small, medium, large) y variantes para formularios y casos de uso reales. Compatible con todas las marcas del design system.

Estados Básicos

1. Default

2. Hover

Pasa el mouse sobre los checkboxes

3. Focus

Click o usa Tab para ver el focus

4. Disabled

5. Indeterminate

Línea horizontal indica estado parcial

6. Error

Borde rojo indica validación fallida

Ejemplo de uso
HTML 
<!-- Estado Default -->
<label class="sb-ui-checkbox">
  <input type="checkbox" class="sb-ui-checkbox__input" />
  <span class="sb-ui-checkbox__box"></span>
  <span class="sb-ui-checkbox__label">Unchecked</span>
</label>

<!-- Estado Checked -->
<label class="sb-ui-checkbox">
  <input type="checkbox" class="sb-ui-checkbox__input" checked />
  <span class="sb-ui-checkbox__box"></span>
  <span class="sb-ui-checkbox__label">Checked</span>
</label>

<!-- Estado Error -->
<label class="sb-ui-checkbox sb-ui-checkbox--error">
  <input type="checkbox" class="sb-ui-checkbox__input" />
  <span class="sb-ui-checkbox__box"></span>
  <span class="sb-ui-checkbox__label">Campo requerido</span>
</label>
