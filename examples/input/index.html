Input

Campo de texto con soporte para todos los estados (default, hover, focus, disabled, success, error), iconos, labels y helper text.

Estados Básicos

Hover y focus se aplican automáticamente al interactuar con el campo.

Default

Texto de ayuda

Con Valor

Input con valor

Con Icono

Input con icono

Disabled

Campo no disponible

Estados de Validación

Estados de validación: Success y Error con sus respectivos iconos y colores.

Success

El campo fue validado correctamente

Error

Este campo es requerido

Labels y Requerimientos

Asterisco rojo para campos requeridos y texto "(opcional)" para campos opcionales.

Campo Requerido

Label incluye asterisco (*) en rojo

Campo Opcional

Label incluye texto "(opcional)"

Tipos de Input

El componente soporta todos los tipos HTML5: text, email, password, tel, url, number, time, etc.

Email

Password (con toggle)

Click en el ojo para mostrar/ocultar (sin JavaScript)

Teléfono

Number

Time

URL

Search

Implementación

Cómo implementar cada ejemplo con el HTML y las clases del componente Input.

Default (label + input + helper) HTML 
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label" for="mi-input">Label Text</label>
  <input id="mi-input" class="sb-ui-input" type="text" placeholder="Placeholder" />
  <span class="sb-ui-input-helper">Texto de ayuda</span>
</div>
Con icono derecho HTML 
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label" for="mi-input">Buscar</label>
  <div class="sb-ui-input-inner">
    <input id="mi-input" class="sb-ui-input sb-ui-input--with-icon" type="text" placeholder="Buscar..." />
    <i class="sb-ui-input-icon fa-solid fa-magnifying-glass"></i>
  </div>
</div>
Disabled HTML 
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label" for="mi-input">Campo deshabilitado</label>
  <input id="mi-input" class="sb-ui-input" type="text" placeholder="No editable" disabled />
  <span class="sb-ui-input-helper">Campo no disponible</span>
</div>
Estado Success HTML 
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label" for="mi-input">Email válido</label>
  <div class="sb-ui-input-inner">
    <input id="mi-input" class="sb-ui-input sb-ui-input--success sb-ui-input--with-icon" type="email" value="usuario@ejemplo.com" />
    <i class="sb-ui-input-icon fa-solid fa-circle-check"></i>
  </div>
  <span class="sb-ui-input-helper">El campo fue validado correctamente</span>
</div>
Estado Error HTML 
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label sb-ui-input-label--required" for="mi-input">Email requerido</label>
  <div class="sb-ui-input-inner">
    <input id="mi-input" class="sb-ui-input sb-ui-input--error sb-ui-input--with-icon" type="email" placeholder="correo@ejemplo.com" />
    <i class="sb-ui-input-icon fa-solid fa-circle-exclamation"></i>
  </div>
  <span class="sb-ui-input-helper">Este campo es requerido</span>
</div>
Campo requerido (asterisco rojo) HTML 
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label sb-ui-input-label--required" for="mi-input">Email</label>
  <input id="mi-input" class="sb-ui-input" type="email" placeholder="tu@email.com" required />
  <span class="sb-ui-input-helper">Label incluye asterisco (*) en rojo</span>
</div>
Campo opcional HTML 
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label sb-ui-input-label--optional" for="mi-input">Teléfono</label>
  <input id="mi-input" class="sb-ui-input" type="tel" placeholder="+57 300 123 4567" />
  <span class="sb-ui-input-helper">Label incluye texto "(opcional)"</span>
</div>
Password con toggle mostrar/ocultar (sin JavaScript) HTML 
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label" for="mi-password">Contraseña</label>
  <input type="checkbox" id="password-toggle" class="sb-ui-input-password-toggle" />
  <div class="sb-ui-input-inner">
    <div class="sb-ui-input-password-wrapper">
      <input id="mi-password" class="sb-ui-input sb-ui-input--with-icon" type="password" placeholder="••••••••" />
      <input class="sb-ui-input sb-ui-input--with-icon" type="text" placeholder="••••••••" tabindex="-1" aria-hidden="true" />
    </div>
    <label for="password-toggle" class="sb-ui-input-icon sb-ui-input-password-toggle-label" title="Mostrar/Ocultar contraseña">
      <i class="fa-solid fa-eye"></i>
      <i class="fa-solid fa-eye-slash"></i>
    </label>
  </div>
</div>
Tipos: email, tel, number, time, url, search HTML 
<!-- Email con icono -->
<div class="sb-ui-input-inner">
  <input class="sb-ui-input sb-ui-input--with-icon" type="email" placeholder="tu@correo.com" />
  <i class="sb-ui-input-icon fa-solid fa-envelope"></i>
</div>

<!-- Teléfono con icono -->
<div class="sb-ui-input-inner">
  <input class="sb-ui-input sb-ui-input--with-icon" type="tel" placeholder="300 123 4567" />
  <i class="sb-ui-input-icon fa-solid fa-phone"></i>
</div>

<!-- Number (sin icono) -->
<input class="sb-ui-input" type="number" placeholder="0" min="0" />

<!-- Time -->
<input class="sb-ui-input" type="time" />

<!-- URL con icono -->
<div class="sb-ui-input-inner">
  <input class="sb-ui-input sb-ui-input--with-icon" type="url" placeholder="https://ejemplo.com" />
  <i class="sb-ui-input-icon fa-solid fa-globe"></i>
</div>
