Input

Componente de campo de texto con múltiples estados (default, hover, focus, disabled, success, error, warning), tamaños (small, medium, large), validaciones (required, optional) y tipos (text, email, password, number, date, tel, url). Compatible con todas las marcas del design system.

Ejemplo de uso HTML 
<!-- Estado Default -->
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label">Label txt</label>
  <input class="sb-ui-input" type="text" placeholder="Placeholder" />
  <span class="sb-ui-input-helper">Help text</span>
</div>

<!-- Estado Error con icono -->
<div class="sb-ui-input-container">
  <label class="sb-ui-input-label">Label txt</label>
  <div style="position: relative">
    <input class="sb-ui-input sb-ui-input--error sb-ui-input--with-icon" type="text" placeholder="Placeholder" />
    <span style="position: absolute; right: 16px; top: 50%; transform: translateY(-50%);">
      <i class="fa-solid fa-xmark"></i>
    </span>
  </div>
  <span class="sb-ui-input-helper">Error message</span>
</div>

Required & Optional

Required

Este campo es requerido

Optional

Este campo es opcional
Ejemplo de uso HTML 
<!-- Campo Requerido -->
<label class="sb-ui-input-label sb-ui-input-label--required">Label txt</label>
<input class="sb-ui-input" type="text" placeholder="Placeholder" required />

<!-- Campo Opcional -->
<label class="sb-ui-input-label sb-ui-input-label--optional">Label txt</label>
<input class="sb-ui-input" type="text" placeholder="Placeholder" />
