Input

Campo de texto con estados (default, hover, focus, disabled, success, error, warning), tamaños (small, medium, large), required/optional y tipos (text, email, password, number, date, tel, url). Componente HTML + CSS de la librería.

Estados

El input puede mostrarse en distintos estados visuales: por defecto (con hover y focus interactivos), deshabilitado, éxito, error y advertencia. Hover y focus se aplican automáticamente al interactuar.
