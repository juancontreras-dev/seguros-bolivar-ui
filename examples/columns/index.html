Columns (Alineación y Orden)

Utilities CSS para controlar la alineacion, justificacion, orden y posicionamiento de columnas dentro de un grid. Permite crear layouts flexibles y responsive sin codigo JavaScript. Compatible con todos los breakpoints del sistema.

Nota: Los fondos verdes y bordes punteados en las demos son estilos ilustrativos (clases demo-item, demo-grid) que no forman parte del bundle. El codigo copiable solo incluye las clases sb-ui-* del Design System. Para visualizar los efectos de alineacion, agrega background y min-height a tus propios elementos.

Alineación Vertical (align-self)

Controla la alineación vertical de una columna individual dentro de su celda de grid. Útil cuando las columnas tienen diferentes alturas.

Align Start

Orden de Columnas (order)

Cambia el orden visual de las columnas sin modificar el HTML. Útil para reorganizar contenido en diferentes breakpoints.

HTML: Primero
order-3
HTML: Segundo
order-1
HTML: Tercero
order-2

El orden visual es: Segundo (order-1), Tercero (order-2), Primero (order-3)

Ejemplo de uso
HTML 
<div class="sb-ui-grid">
  <div class="sb-ui-col-12 sb-ui-col-sm-4 sb-ui-col-order-3">Aparece tercero</div>
  <div class="sb-ui-col-12 sb-ui-col-sm-4 sb-ui-col-order-1">Aparece primero</div>
  <div class="sb-ui-col-12 sb-ui-col-sm-4 sb-ui-col-order-2">Aparece segundo</div>
</div>
HTML: Primero
order-last
HTML: Segundo
default
HTML: Tercero
order-first

order-first (-1) y order-last (999) para posicionamiento extremo

Ejemplo de uso
HTML 
<div class="sb-ui-grid">
  <div class="sb-ui-col-12 sb-ui-col-sm-4 sb-ui-col-order-first">Siempre primero</div>
  <div class="sb-ui-col-12 sb-ui-col-sm-4">Sin order (default)</div>
  <div class="sb-ui-col-12 sb-ui-col-sm-4 sb-ui-col-order-last">Siempre último</div>
</div>

Posicionamiento Explícito (col-start)

Define explícitamente en qué columna comienza un elemento. Útil para crear layouts complejos y asimétricos.

Start 1
Span 3
Start 7
Span 6

Grid de 12 columnas: primer item comienza en col 1 (ocupa 3), segundo en col 7 (ocupa 6). Columnas 4-6 quedan vacías.

Ejemplo de uso
HTML 
<div class="sb-ui-grid">
  <div class="sb-ui-col-3 sb-ui-col-start-1">
    Comienza en columna 1, ocupa 3 columnas
  </div>
  <div class="sb-ui-col-6 sb-ui-col-start-7">
    Comienza en columna 7, ocupa 6 columnas
  </div>
</div>

Columns Responsive

Todas las utilities de columns tienen variantes responsive. Cambia el comportamiento según el tamaño de pantalla.

Orden responsive

Mobile: 3° → Tablet: 1°
Mobile: 2° → Tablet: 2°
Mobile: 1° → Tablet: 3°

Redimensiona la ventana: El orden se invierte en tablets (≥768px)

Ejemplo de uso
HTML 
<div class="sb-ui-grid">
  <div class="sb-ui-col-12 sb-ui-col-sm-4 sb-ui-col-order-3 sb-ui-col-order-md-1">
    Mobile: 3° → Tablet: 1°
  </div>
  <div class="sb-ui-col-12 sb-ui-col-sm-4 sb-ui-col-order-2 sb-ui-col-order-md-2">
    Mobile: 2° → Tablet: 2°
  </div>
  <div class="sb-ui-col-12 sb-ui-col-sm-4 sb-ui-col-order-1 sb-ui-col-order-md-3">
    Mobile: 1° → Tablet: 3°
  </div>
</div>

Alineación responsive (align-self)

Normal (tall)
Mobile: start → Tablet: center → Desktop: end
Normal (tall)

Redimensiona la ventana: La alineación vertical cambia en cada breakpoint

Ejemplo de uso
HTML 
<div class="sb-ui-grid">
  <div class="sb-ui-col-align-self-start sb-ui-col-align-self-md-center sb-ui-col-align-self-lg-end">
    Mobile arriba, tablet centrado, desktop abajo
  </div>
</div>

<div class="sb-ui-grid">
  <div class="sb-ui-col-justify-self-start sb-ui-col-justify-self-md-center sb-ui-col-justify-self-lg-end">
    Mobile izquierda, tablet centrado, desktop derecha
  </div>
</div>
