Columns (Alineación y Orden)

Utilities CSS para controlar la alineación, justificación, orden y posicionamiento de columnas dentro de un grid. Permite crear layouts flexibles y responsive sin código JavaScript. Compatible con todos los breakpoints del sistema.

Alineación Vertical (align-self)

Controla la alineación vertical de una columna individual dentro de su celda de grid. Útil cuando las columnas tienen diferentes alturas.

Start (inicio)

Normal
Align Start
Normal
Ejemplo de uso
HTML 
<div class="sb-ui-grid">
  <div class="sb-ui-col-12 sb-ui-col-md-4 sb-ui-col-align-self-start">
    Alineado al inicio
  </div>
  <div class="sb-ui-col-12 sb-ui-col-md-4">Normal</div>
  <div class="sb-ui-col-12 sb-ui-col-md-4">Normal</div>
</div>

Orden de Columnas (order)

Cambia el orden visual de las columnas sin modificar el HTML. Útil para reorganizar contenido en diferentes breakpoints.

HTML: Primero
order-3
HTML: Segundo
order-1
HTML: Tercero
order-2

El orden visual es: Segundo (order-1), Tercero (order-2), Primero (order-3)

Ejemplo de uso
HTML 
<div class="sb-ui-grid">
  <div class="sb-ui-col-order-3">Aparece tercero</div>
  <div class="sb-ui-col-order-1">Aparece primero</div>
  <div class="sb-ui-col-order-2">Aparece segundo</div>
</div>
HTML: Primero
order-last
HTML: Segundo
default
HTML: Tercero
order-first

order-first (-1) y order-last (999) para posicionamiento extremo

Ejemplo de uso
HTML 
<!-- Orden extremo -->
<div class="sb-ui-grid">
  <div class="sb-ui-col-order-first">Siempre primero</div>
  <div class="sb-ui-col-order-last">Siempre último</div>
</div>

Posicionamiento Explícito (col-start)

Define explícitamente en qué columna comienza un elemento. Útil para crear layouts complejos y asimétricos.

Start 1
Span 3
Start 7
Span 6

Grid de 12 columnas: primer item comienza en col 1, segundo en col 7 (deja gap de columnas 4-6)

Ejemplo de uso
HTML 
<!-- Grid de 12 columnas (usa grid.css para crear el grid) -->
<div class="sb-ui-grid">
  <div class="sb-ui-col-4 sb-ui-col-start-1">
    Comienza en columna 1, ocupa 4 columnas
  </div>
  <div class="sb-ui-col-6 sb-ui-col-start-7">
    Comienza en columna 7, ocupa 6 columnas
  </div>
</div>

Columns Responsive

Todas las utilities de columns tienen variantes responsive. Cambia el comportamiento según el tamaño de pantalla.

Mobile: 3° → Tablet: 1°
Mobile: 2° → Tablet: 2°
Mobile: 1° → Tablet: 3°

Redimensiona la ventana: El orden se invierte en tablets (≥768px)

Ejemplo de uso
HTML 
<!-- Orden responsive -->
<div class="sb-ui-col-order-1 sb-ui-col-order-lg-3">
  Mobile primero, desktop último
</div>

<!-- Alineación responsive -->
<div class="sb-ui-col-align-self-start sb-ui-col-align-self-md-center">
  Mobile arriba, tablet centrado
</div>

<!-- Breakpoints: sm (576px), md (768px), lg (992px), xl (1200px), xxl (1400px) -->
