Accordion

Componente de acordeón para mostrar y ocultar contenido. Usa el elemento nativo <details> y <summary> (sin JavaScript). Compatible con todas las marcas del design system.

Uso / aplicación

Acordeón primario con icono de inicio, botón de acción opcional y chevron. El borde es gris por defecto; al expandir cambia a verde con texto verde.

Información general

Este contenido no es accesible cuando el acordeón está deshabilitado.

Código

Estructura semántica del componente accordion con todas las piezas opcionales.

Estructura completa HTML 
<!-- Con acción (pill button) -->
<details class="sb-ui-accordion sb-ui-accordion--primary">
  <summary class="sb-ui-accordion__header">
    <i class="fa-solid fa-globe sb-ui-accordion__icon-start"></i>
    <span class="sb-ui-accordion__label">Título del acordeón</span>
    <button class="sb-ui-accordion__action" type="button"
            onclick="event.stopPropagation(); event.preventDefault();">
      <i class="fa-solid fa-circle-down"></i>
      Descargar
    </button>
    <i class="fa-solid fa-chevron-down sb-ui-accordion__icon-end"></i>
  </summary>
  <div class="sb-ui-accordion__content">
    Contenido del acordeón.
  </div>
</details>

<!-- Sin acción -->
<details class="sb-ui-accordion sb-ui-accordion--primary" open>
  <summary class="sb-ui-accordion__header">
    <i class="fa-solid fa-globe sb-ui-accordion__icon-start"></i>
    <span class="sb-ui-accordion__label">Título expandido</span>
    <i class="fa-solid fa-chevron-down sb-ui-accordion__icon-end"></i>
  </summary>
  <div class="sb-ui-accordion__content">
    Contenido visible por defecto.
  </div>
</details>

<!-- Disabled -->
<details class="sb-ui-accordion sb-ui-accordion--primary sb-ui-accordion--disabled">
  <summary class="sb-ui-accordion__header">
    <i class="fa-solid fa-globe sb-ui-accordion__icon-start"></i>
    <span class="sb-ui-accordion__label">No interactivo</span>
    <i class="fa-solid fa-chevron-down sb-ui-accordion__icon-end"></i>
  </summary>
  <div class="sb-ui-accordion__content">
    Contenido no accesible.
  </div>
</details>
