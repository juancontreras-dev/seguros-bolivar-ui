Accordion

Componente de acordeón para mostrar y ocultar contenido. Usa el elemento nativo <details> y <summary> (sin JavaScript). Compatible con todas las marcas del design system.

Ejemplo básico (Primary)

Haz clic en cada título para expandir o colapsar. El primero viene abierto por defecto.

Preguntas frecuentes

¿Qué es Seguros Bolívar UI?

Es un design system completo con componentes reutilizables para crear interfaces de usuario consistentes.

¿Cómo puedo instalar el design system?

Puedes instalarlo vía NPM o usar el CDN. Revisa la guía de instalación para más detalles.

¿Es compatible con todas las marcas?

Sí, el design system soporta 6 marcas: Seguros Bolívar, Davivienda, Jelpit, Cien Cuadras, Doctor Aki y White Label.

Ejemplo de uso HTML 
<details class="sb-ui-accordion sb-ui-accordion--primary" open>
  <summary class="sb-ui-accordion__header">
    <span class="sb-ui-accordion__label">¿Tu pregunta?</span>
    <i class="fa-solid fa-chevron-down sb-ui-accordion__icon-end"></i>
  </summary>
  <div class="sb-ui-accordion__content">
    Contenido del acordeón.
  </div>
</details>

Con icono al inicio (Primary)

Incluye un icono opcional al inicio del header.

¿Qué coberturas incluye?

Las coberturas dependen del producto. Revisa la póliza o contacta a tu asesor.

¿Cuánto tarda la aprobación?

El proceso suele tomar entre 24 y 72 horas hábiles según el tipo de trámite.

Tamaños (Small y Large)

Clases sb-ui-accordion--small y sb-ui-accordion--large.

Small

Acordeón pequeño
Contenido compacto.

Large

Acordeón grande
Contenido con más espacio tipográfico.

Guía de clases

Clase Descripción
.sb-ui-accordion Contenedor (usar en <details>)
.sb-ui-accordion--primary Variante primaria (borde verde)
.sb-ui-accordion--secondary Variante secundaria
.sb-ui-accordion--small / --large Tamaño pequeño o grande
.sb-ui-accordion__header Cabecera clickeable (usar en <summary>)
.sb-ui-accordion__label Texto del título
.sb-ui-accordion__icon-end Icono chevron (rota al abrir)
.sb-ui-accordion__content Contenido expandible
open Atributo en <details> para abierto por defecto
