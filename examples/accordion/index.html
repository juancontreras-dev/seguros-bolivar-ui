Accordion

Componente de acordeón para mostrar y ocultar contenido de forma colapsable. Compatible con todas las marcas del design system.

Ejemplo Básico

Click en los títulos para expandir/colapsar

¿Qué es Seguros Bolívar UI?

Es un design system completo con componentes reutilizables para crear interfaces de usuario consistentes.
¿Cómo puedo instalar el design system?

Puedes instalarlo vía NPM o usar el CDN. Revisa la guía de instalación para más detalles.
¿Es compatible con todas las marcas?

Sí, el design system soporta 6 marcas: Seguros Bolívar, Davivienda, Jelpit, Cien Cuadras, Doctor Aki y White Label.
Ejemplo de uso HTML 
<!-- Accordion con Web Component -->
<sb-ui-accordion>
  <sb-ui-accordion-item open>
    <div slot="title">Título 1</div>
    <div slot="content">Contenido 1</div>
  </sb-ui-accordion-item>

  <sb-ui-accordion-item>
    <div slot="title">Título 2</div>
    <div slot="content">Contenido 2</div>
  </sb-ui-accordion-item>
</sb-ui-accordion>
