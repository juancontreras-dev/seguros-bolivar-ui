Select

Componente de selección desplegable (dropdown) con múltiples estados (default, hover, focus, disabled, error), tamaños (small, medium, large) y variantes para formularios y casos de uso reales. Compatible con todas las marcas del design system.

Estados

1. Default

Seleccione su país de residencia

2. Focus

Click para ver el borde verde

3. Disabled

Campo deshabilitado

4. Error

Este campo es obligatorio

5. Con valor seleccionado

Ejemplo de uso HTML 
<!-- Estado Default -->
<div class="sb-ui-select-container">
  <label class="sb-ui-select-label">País</label>
  <select class="sb-ui-select">
    <option value="">Seleccione...</option>
    <option value="co">Colombia</option>
    <option value="mx">México</option>
  </select>
  <span class="sb-ui-select-helper">Texto de ayuda</span>
</div>

<!-- Estado Error -->
<select class="sb-ui-select sb-ui-select--error">
  <option value="">Seleccione...</option>
</select>

Casos de Uso

Selección de País

Campo obligatorio

Tipo de Seguro

Con Validación

Debe seleccionar un tipo de documento
Ejemplo de uso HTML 
<!-- Select con validación -->
<div class="sb-ui-select-container">
  <label class="sb-ui-select-label">País *</label>
  <select class="sb-ui-select" required>
    <option value="">Seleccione...</option>
    <option value="co">Colombia</option>
    <option value="mx">México</option>
  </select>
  <span class="sb-ui-select-helper">Campo obligatorio</span>
</div>
