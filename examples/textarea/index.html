Textarea

Componente de campo de texto multilínea con múltiples estados (default, hover, focus, disabled, success, error), tamaños configurables y contador de caracteres opcional. Compatible con todas las marcas del design system.

Estados

1. Default

Campo de texto de varias líneas

2. Focus

Haz clic en el campo para ver el borde verde (Figma)

Borde verde en focus

3. Disabled

No editable

4. Error

Este campo es obligatorio

5. Success

Campo completado correctamente

6. Read-only

Contenido no editable
Ejemplo de uso HTML 
<!-- Estado Default -->
<div class="sb-ui-textarea-container">
  <label class="sb-ui-textarea-label" for="...">Comentarios</label>
  <textarea id="..." class="sb-ui-textarea" rows="4" placeholder="Escribe aquí..."></textarea>
  <span class="sb-ui-textarea-helper"><i class="fa-solid fa-circle-info" aria-hidden="true"></i> Texto de ayuda</span>
</div>

<!-- Estado Error -->
<div class="sb-ui-textarea-container">
  <label class="sb-ui-textarea-label sb-ui-textarea-label--required" for="...">Descripción</label>
  <textarea id="..." class="sb-ui-textarea sb-ui-textarea--error" rows="4"></textarea>
  <span class="sb-ui-textarea-helper sb-ui-textarea-helper--error"><i class="fa-solid fa-circle-exclamation" aria-hidden="true"></i> Este campo es obligatorio</span>
</div>

Tamaños (rows)

Small (3 rows)

Medium (5 rows)

Large (8 rows)

Ejemplo de uso HTML 
<!-- Small (3 rows) -->
<textarea class="sb-ui-textarea" rows="3" placeholder="Texto corto"></textarea>

<!-- Medium (5 rows) -->
<textarea class="sb-ui-textarea" rows="5" placeholder="Texto medio"></textarea>

<!-- Large (8 rows) -->
<textarea class="sb-ui-textarea" rows="8" placeholder="Texto largo"></textarea>

Casos de Uso

Formulario de Contacto

Mínimo 20 caracteres

Reseña de Producto

200/500 caracteres

Reporte de Incidencia

Este campo es obligatorio
Ejemplo de uso HTML 
<!-- Formulario de contacto -->
<div class="sb-ui-textarea-container">
  <label class="sb-ui-textarea-label sb-ui-textarea-label--required" for="msg">Mensaje</label>
  <textarea id="msg" class="sb-ui-textarea" rows="6" placeholder="Escribe tu mensaje..." required></textarea>
  <span class="sb-ui-textarea-helper"><i class="fa-solid fa-circle-info" aria-hidden="true"></i> Mínimo 20 caracteres</span>
</div>
