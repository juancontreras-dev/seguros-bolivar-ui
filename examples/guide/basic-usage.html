Uso Básico

Estructura HTML Mínima

Este es un ejemplo completo de una página HTML usando el Design System:

<!DOCTYPE html> <html lang="es" data-brand="seguros-bolivar" data-theme="light"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Mi App - Seguros Bolívar</title> <!-- CSS del Design System --> <link rel="stylesheet" href="https://unpkg.com/@seguros-bolivar/ui-bundle@latest/dist/sb-ui-seguros-bolivar-light.min.css"> <!-- Web Components (opcional) --> <script type="module" src="https://unpkg.com/@seguros-bolivar/ui-bundle@latest/dist/sb-ui-components.min.js"></script> </head> <body> <!-- Tu contenido aquí --> <div style="padding: 2rem;"> <h1>¡Bienvenido a Seguros Bolívar!</h1> <button class="sb-ui-button sb-ui-button--primary sb-ui-button--fill"> Botón Principal </button> <input type="text" class="sb-ui-input" placeholder="Ingresa tu nombre"> </div> </body> </html>

Atributos data-brand y data-theme

¡Clave para la personalización! El Design System utiliza los atributos data-brand y data-theme en el elemento <html> para definir la marca y el tema visual de toda la interfaz.
El valor de data-brand es el que realmente cambia la identidad visual de la marca.

<!-- Configuración de marca y tema en el elemento raíz --> <html lang="es" data-brand="seguros-bolivar" data-theme="light">
Importante

Ambos atributos deben coincidir exactamente con el archivo CSS cargado.
Si data-brand no coincide con el nombre de la marca en el CSS, los estilos de marca no se aplicarán.

Marcas disponibles

El valor de data-brand define la marca visual. Debe coincidir exactamente con la columna resaltada:

Marca data-brand (clave) Archivo CSS
Seguros Bolívar seguros-bolivar sb-ui-seguros-bolivar-{theme}.min.css
Davivienda davivienda sb-ui-davivienda-{theme}.min.css
Jelpit jelpit sb-ui-jelpit-{theme}.min.css
Cien Cuadras cien-cuadras sb-ui-cien-cuadras-{theme}.min.css
Doctor Aki doctor-aki sb-ui-doctor-aki-{theme}.min.css
White Label white-label sb-ui-white-label-{theme}.min.css

Temas disponibles

El valor de data-theme define el modo visual (claro u oscuro):

Tema data-theme (clave) Descripción
Claro light Tema claro (fondo blanco, texto oscuro)
Oscuro dark Tema oscuro (fondo oscuro, texto claro)
Consejo

Para cambiar el tema, solo modifica data-theme y el CSS correspondiente. Ejemplo:

<html lang="es" data-brand="seguros-bolivar" data-theme="dark">
<link rel="stylesheet" href="sb-ui-seguros-bolivar-dark.min.css">
Si el valor no coincide, el tema no se aplicará correctamente.

Ejemplo completo con Davivienda

<!DOCTYPE html> <html lang="es" data-brand="davivienda" data-theme="light"> <head> <meta charset="UTF-8"> <title>Mi App - Davivienda</title> <!-- CSS de Davivienda Light --> <link rel="stylesheet" href="https://unpkg.com/@seguros-bolivar/ui-bundle@latest/dist/sb-ui-davivienda-light.min.css"> </head> <body> <!-- Los componentes usarán automáticamente los colores de Davivienda --> <button class="sb-ui-button sb-ui-button--primary sb-ui-button--fill"> Botón Davivienda </button> </body> </html>

Nomenclatura BEM

Todos los componentes siguen la metodología BEM (Block, Element, Modifier) con el prefijo sb-ui-:

Patrón Ejemplo Descripción
.sb-ui-{block} .sb-ui-button Bloque base del componente
.sb-ui-{block}--{modifier} .sb-ui-button--primary Modificador de variante
.sb-ui-{block}--{size} .sb-ui-button--small Modificador de tamaño
.sb-ui-{block}--{state} .sb-ui-button--disabled Modificador de estado
¿Por qué BEM?

BEM hace que el CSS sea predecible, reutilizable y escalable. El prefijo sb-ui- evita conflictos con otros estilos de tu proyecto.

Ejemplos de Componentes Básicos

Botones

Los botones tienen 4 variantes (primary, secondary, danger, neutral) y 3 estilos (fill, outline, text):

<!-- Botón primario sólido --> <button class="sb-ui-button sb-ui-button--primary sb-ui-button--fill"> Botón Primario </button> <!-- Botón secundario outline --> <button class="sb-ui-button sb-ui-button--secondary sb-ui-button--outline"> Botón Secundario </button> <!-- Botón pequeño --> <button class="sb-ui-button sb-ui-button--primary sb-ui-button--fill sb-ui-button--small"> Botón Pequeño </button> <!-- Botón deshabilitado --> <button class="sb-ui-button sb-ui-button--primary sb-ui-button--fill" disabled> Deshabilitado </button>

Inputs

Los campos de entrada tienen estados de validación y mensajes de ayuda:

<!-- Input básico --> <input type="text" class="sb-ui-input" placeholder="Tu nombre"> <!-- Input con estado de error --> <input type="email" class="sb-ui-input sb-ui-input--error" placeholder="Correo inválido"> <!-- Input con estado de éxito --> <input type="text" class="sb-ui-input sb-ui-input--success" value="Dato válido"> <!-- Input deshabilitado --> <input type="text" class="sb-ui-input" placeholder="Deshabilitado" disabled>

Select

Las listas desplegables mantienen la consistencia visual:

<select class="sb-ui-select"> <option value="">Selecciona una opción</option> <option value="1">Opción 1</option> <option value="2">Opción 2</option> <option value="3">Opción 3</option> </select>

Checkbox y Toggle

Controles de selección accesibles:

<!-- Checkbox --> <label style="display: flex; align-items: center; gap: 0.5rem;"> <input type="checkbox" class="sb-ui-checkbox"> <span>Acepto los términos</span> </label> <!-- Toggle --> <label style="display: flex; align-items: center; gap: 0.5rem;"> <input type="checkbox" class="sb-ui-toggle"> <span>Activar notificaciones</span> </label>
