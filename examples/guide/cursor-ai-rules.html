Reglas Cursor AI

Para garantizar una implementación consistente y correcta del Design System de Seguros Bolívar, es importante configurar las reglas de Cursor AI en cada proyecto que utilice la librería.

Repositorio de Reglas Cursor AI

Descarga las reglas oficiales para configurar Cursor AI en tu proyecto.

Ver en GitHub

¿Por qué usar estas reglas?

Las reglas de Cursor AI ayudan a:

  • Mantener consistencia en la implementación de componentes
  • Evitar errores comunes al usar el Design System
  • Acelerar el desarrollo con sugerencias contextuales
  • Garantizar el uso correcto de variables CSS y nomenclatura BEM

Archivos de Reglas Disponibles

1. Variables CSS (variables-01-css.mdc)

Define las reglas para el uso correcto de CSS Custom Properties del Design System.

Uso Estado
var(--sb-ui-color-primary-base) ✓ Usar
#038450 (color hardcodeado) ✗ Prohibido
var(--sb-ui-spacing-base) ✓ Usar
16px (valor hardcodeado) ✗ Prohibido

2. Implementación CDN (implementacion-01-cdn.mdc)

Guía para la correcta implementación del Design System mediante CDN.

<!-- CSS del Design System -->
<link rel="stylesheet" 
  href="https://unpkg.com/@seguros-bolivar/ui-bundle@latest/dist/sb-ui-seguros-bolivar-light.min.css">

<!-- JavaScript (opcional, para Web Components) -->
<script type="module" 
  src="https://unpkg.com/@seguros-bolivar/ui-bundle@latest/dist/sb-ui-components.min.js"></script>

3. Componentes (componentes-01-sb-ui.mdc)

Reglas para el uso correcto de los componentes y su nomenclatura BEM.

Patrón Ejemplo Estado
Bloque .sb-ui-button ✓ Correcto
Modificador .sb-ui-button--primary ✓ Correcto
Elemento .sb-ui-input-label ✓ Correcto
Custom class .my-button ✗ Evitar

Instalación de las Reglas

  1. Clona o descarga los archivos .mdc del repositorio
  2. Copia los archivos a la carpeta .cursor/rules/ de tu proyecto
  3. Reinicia Cursor AI para que las reglas tomen efecto
# Estructura de carpetas
tu-proyecto/
├── .cursor/
│   └── rules/
│       ├── variables-01-css.mdc
│       ├── implementacion-01-cdn.mdc
│       └── componentes-01-sb-ui.mdc
├── src/
└── ...
Importante: Es recomendable agregar estas reglas a cada proyecto que utilice la librería Seguros Bolívar UI para mantener la consistencia y aprovechar las sugerencias inteligentes de Cursor AI.

Beneficios

  • Autocompletado inteligente: Cursor sugerirá las variables y clases correctas del Design System
  • Validación en tiempo real: Alertas cuando se usen valores hardcodeados en lugar de variables
  • Documentación contextual: Acceso rápido a la documentación de cada componente
  • Mejores prácticas: Cursor guiará hacia patrones de código consistentes
