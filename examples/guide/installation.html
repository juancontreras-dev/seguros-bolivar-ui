Inicio Rápido - Solo CDN

Copia y pega estas etiquetas en el <head> de tu HTML:

CSS (Estilos):
<link rel="stylesheet" href="https://juancontreras-dev.github.io/seguros-bolivar-ui/dist/sb-ui-seguros-bolivar-light.min.css">
JavaScript (Web Components - opcional):
<script type="module" src="https://juancontreras-dev.github.io/seguros-bolivar-ui/dist/sb-ui-components.min.js"></script>

Tip: No olvides agregar data-brand="seguros-bolivar" y data-theme="light" al <html>

Uso con CDN – Copy-Paste de componentes
  • Los snippets que se muestran en cada página de componente (Columns, Breadcrumb, Tabs, etc.) son los que debes copiar: solo requieren el CSS del bundle (y el script si usas Web Components).
  • El aspecto de la página completa del demo (títulos, secciones, recuadros, bloques de código) no está en el bundle y no es necesario para usar el componente; es solo presentación de la documentación.

Existen tres formas principales de usar Seguros Bolívar UI en tu proyecto. Elige la que mejor se adapte a tus necesidades:

1. CDN (Recomendado para Prototipos)

La forma más rápida de empezar. Simplemente incluye los archivos CSS y JS desde un CDN público:

¡IMPORTANTE!

Recuerda agregar los atributos data-brand="seguros-bolivar" y data-theme="light" al elemento <html>.

CDN (GitHub Pages)

<!DOCTYPE html> <html lang="es" data-brand="seguros-bolivar" data-theme="light"> <head> <!-- CSS del Design System --> <link rel="stylesheet" href="https://juancontreras-dev.github.io/seguros-bolivar-ui/dist/sb-ui-seguros-bolivar-light.min.css"> <!-- Web Components (opcional) --> <script type="module" src="https://juancontreras-dev.github.io/seguros-bolivar-ui/dist/sb-ui-components.min.js"></script> </head> <body> <button class="sb-ui-button sb-ui-button--primary sb-ui-button--fill"> ¡Hola Mundo! </button> </body> </html>
Ventajas del CDN:
  • ✅ Configuración instantánea - sin instalación
  • ✅ Caché global - carga más rápida
  • ✅ Ideal para prototipos y demos
  • ✅ Sin gestión de dependencias
Tus propios estilos y la cascada CSS

La librería usa @layer para sus estilos. Las reglas CSS sin capa (tus hojas o estilos inline) tienen prioridad sobre las que están dentro de una capa. Si tus estilos “rompen” un componente, evita selectores que apunten a los mismos elementos que la librería (p. ej. div { display: block; } puede anular el display: grid del grid). Opcional: pon tus estilos en una capa que venga antes, p. ej. @layer user; y carga el bundle después.

2. NPM (Recomendado para Producción)

Para proyectos en producción, instala el paquete como una dependencia:

# NPM npm install @seguros-bolivar/ui-bundle # PNPM pnpm add @seguros-bolivar/ui-bundle # Yarn yarn add @seguros-bolivar/ui-bundle

Luego importa en tu aplicación:

// En tu archivo principal (ej: main.js, index.js) import '@seguros-bolivar/ui-bundle/dist/sb-ui-seguros-bolivar-light.min.css'; import '@seguros-bolivar/ui-bundle/dist/sb-ui-components.min.js';
Ventajas de NPM:
  • ✅ Control de versiones preciso
  • ✅ Optimización con bundler (Webpack, Vite, etc.)
  • ✅ Tree-shaking disponible
  • ✅ Integración con sistemas de build
