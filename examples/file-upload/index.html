File Upload

Componente de carga de archivos con drag & drop, múltiples estados (default, uploading, success, error), validaciones de tamaño y formato, y feedback visual completo. Compatible con todas las marcas del design system.

Demo Funcional

Zona de arrastre completamente funcional con drag & drop y selección manual

Interactive Demo

Arrastre y suelte sus documentos aquí.

El peso máximo por archivo es 20 MB. Formatos permitidos: .jpg, .png, .jpeg, .pdf.

Ejemplo de uso
HTML 
<div class="sb-ui-file-upload-wrapper">
  <label class="sb-ui-file-upload__label">Documento</label>

  <div class="sb-ui-file-upload-container">

    <!-- Input oculto correctamente -->
    <input 
      type="file" 
      id="fileInput"
      class="sb-ui-file-upload-input"
      accept=".jpg,.jpeg,.png,.pdf"
      hidden
    />

    <!-- Dropzone -->
    <div class="sb-ui-file-upload-dropzone">
      <p class="sb-ui-file-upload-dropzone__text">
        Arrastre y suelte sus documentos aquí.
      </p>
      <p class="sb-ui-file-upload__help">
        Máx. 20 MB. Formatos: .jpg, .png, .pdf.
      </p>
    </div>

    <!-- Botón visual -->
    <label 
      for="fileInput"
      class="sb-ui-button sb-ui-button--primary sb-ui-button--fill sb-ui-file-upload__select-button">
      Seleccionar archivo
    </label>

  </div>
</div>
