CSS Grid (Utilities Avanzadas)

Utilities CSS avanzadas para layouts complejos con CSS Grid. Auto-fit, auto-fill, spanning, y alineación de contenido. Para casos más allá del sistema de 12 columnas. Define grids personalizadas con máxima flexibilidad.

Grid-Cols: Columnas Iguales (.sb-ui-grid-cols-*)

Ejemplo de uso HTML 
<!-- Grid de 4 columnas iguales -->
<div style="display: grid; grid-template-columns: repeat(4, 1fr); gap: 1rem;">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
</div>

Grid-Rows: Filas Iguales (.sb-ui-grid-rows-*)

Ejemplo de uso HTML 
<!-- Grid con 3 filas iguales -->
<div style="
  display: grid;
  grid-template-rows: repeat(3, 150px);
  gap: 1rem;
">
  <div>Fila 1</div>
  <div>Fila 2</div>
  <div>Fila 3</div>
</div>

Ejemplo de uso HTML 
<!-- Colspan: ocupa 2 columnas -->
<div style="grid-column: span 2;">Wide item</div>

<!-- Rowspan: ocupa 2 filas -->
<div style="grid-row: span 2;">Tall item</div>

<!-- Combinado: 2x2 -->
<div style="grid-column: span 2; grid-row: span 2;">2x2 item</div>

Ejemplo de uso HTML 
<!-- Centrar todos los items en sus celdas -->
<div style="display: grid; place-items: center;">
  <div>Centrado</div>
</div>

<!-- place-items valores: start, center, end, stretch -->
<!-- place-content valores: start, center, end, space-between, space-around, space-evenly -->

<!-- Separar: align-items (vertical), justify-items (horizontal) -->
<div style="
  display: grid;
  align-items: center;
  justify-items: center;
"></div>
