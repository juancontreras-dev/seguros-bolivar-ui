CSS Grid (Utilities Avanzadas)

Utilities CSS avanzadas para layouts complejos con CSS Grid. Auto-fit, auto-fill, spanning, y alineación de contenido. Para casos más allá del sistema de 12 columnas. Define grids personalizadas con máxima flexibilidad.

Grid-Cols: Columnas Iguales (.sb-ui-grid-cols-*)

Ejemplo de uso HTML

  <div>Item 1</div>

  <div>Item 4</div>

Auto-Fit: Columnas Responsivas (.sb-ui-grid-cols-auto-fit)

Ajusta automaticamente el numero de columnas al espacio disponible. Cada columna tiene un minimo de 200px y se expande para llenar el contenedor.

Auto 1
Auto 2
Auto 3
Auto 4
Auto 5
Auto 6

Redimensiona la ventana para ver como las columnas se reorganizan automaticamente.

Ejemplo de uso
HTML 
<div class="sb-ui-grid-cols-auto-fit sb-ui-gap-3">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
</div>

Grid-Rows: Filas Iguales (.sb-ui-grid-rows-*)

Crea un grid con N filas iguales. Útil para layouts verticales o tabulares donde cada fila tiene la misma altura.

4 Filas con 2 Columnas

Ejemplo de uso HTML 
<div style="
  display: grid;
  grid-template-rows: repeat(3, 150px);
  gap: 1rem;
">
  <div>Fila 1</div>
  <div>Fila 2</div>
  <div>Fila 3</div>
</div>
