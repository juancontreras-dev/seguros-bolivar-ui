Componentes Modales

Ventana modal con 3 variantes de tamano (Small, Medium, Large). Web Component con slots personalizables, cierre por ESC o backdrop, animaciones y bloqueo de scroll. Contenido flexible: texto, formularios, grids.

Especificaciones de Tamano

Variante max-inline-size max-block-size Atributo
Small min(464px, 90%) 45dvb size="small"
Medium min(716px, 90%) 82dvb size="medium"
Large min(928px, 90%) 82dvb size="large"

Small Modal Pequeno

Ideal para confirmaciones, alertas breves o acciones simples. Ancho objetivo ~464px.

Confirmacion

Modal de confirmacion con texto breve y dos acciones.

Alerta informativa

Modal sin footer, cierre por X o ESC unicamente.

Modal Small - Ejemplo de uso
HTML 
<sb-ui-modal id="modal-small" title="Confirmar accion" size="small">
  <p>Este es un modal tamaño small</p>

  <div slot="footer">
    <button class="sb-ui-button sb-ui-button--secondary sb-ui-button--fill sb-ui-button--small"
            onclick="document.getElementById('modal-small').close()">
      Cancelar
    </button>
    <button class="sb-ui-button sb-ui-button--primary sb-ui-button--fill sb-ui-button--small"
            onclick="document.getElementById('modal-small').close()">
      Confirmar
    </button>
  </div>
</sb-ui-modal>

<!-- Abrir el modal -->
<button class="sb-ui-button sb-ui-button--primary sb-ui-button--fill" onclick="document.getElementById('modal-small').openModal()">
  Abrir Modal Small
</button>

Medium Modal Mediano

Ideal para formularios, detalles de producto o contenido intermedio. Ancho objetivo ~716px. Este es el tamano por defecto si no se especifica el atributo size.

Formulario

Modal con formulario de contacto completo y validacion.

Detalles de producto

Modal con texto largo, datos y acciones.

Sin cierre por backdrop

Modal persistente que solo se cierra con botones.

API del Componente

Propiedades y metodos JS 
// Propiedades (atributos HTML)
// title             - String  - Titulo del modal
// size              - String  - 'small' | 'medium' | 'large' (default: 'medium')
// open              - Boolean - Estado abierto/cerrado (tambien: modal.open = true)
// close-on-backdrop - Boolean - Cerrar al hacer clic fuera (default: true)
// show-close-button - Boolean - Mostrar boton X (default: true)

// Metodos
const modal = document.getElementById('mi-modal');
modal.openModal();  // Abre el modal
modal.close();      // Cierra el modal

// Eventos
modal.addEventListener('sb-ui-modal-open', () => console.log('Abierto'));
modal.addEventListener('sb-ui-modal-close', () => console.log('Cerrado'));

// Slots
// (default)  - Contenido del body
// header     - Header personalizado (reemplaza title)
// footer     - Footer con botones de accion

// CSS Parts (para estilos personalizados)
// backdrop, dialog, header, body, footer, close-button
