Modal

Componente de ventana modal (dialog) con múltiples tamaños (small, medium, large, fullscreen) y variantes para confirmaciones, formularios y contenido extenso. Compatible con todas las marcas del design system.

Tamaños

Click en los botones para ver cada tamaño de modal

Small

Medium

Large

Ejemplo de uso HTML 
<!-- Web Component Modal -->
<sb-ui-modal id="myModal" size="medium">
  <div slot="header">Título del Modal</div>
  <div slot="body">Contenido del modal...</div>
  <div slot="footer">
    <button class="sb-ui-button sb-ui-button--primary">Aceptar</button>
  </div>
</sb-ui-modal>

<!-- Abrir modal con JavaScript -->
<button onclick="document.getElementById('myModal').open()">
  Abrir Modal
</button>
