Código de Ejemplo

Uso Básico

Ejemplo de uso HTML 

<!-- HTML -->
<button onclick="document.getElementById('myModal').openModal()">Abrir Modal</button>

<sb-ui-modal id="myModal" title="Mi Modal">
  <p>Contenido del modal</p>
  <div slot="footer">
    <button class="sb-ui-button sb-ui-button--tertiary" onclick="document.getElementById('myModal').close()">Cancelar</button>
    <button class="sb-ui-button sb-ui-button--primary" onclick="document.getElementById('myModal').close()">Aceptar</button>
  </div>
</sb-ui-modal>

Con JavaScript

Ejemplo de uso JavaScript 
const modal = document.getElementById('myModal');
modal.openModal();
modal.close();
modal.addEventListener('sb-ui-modal-open', () => console.log('Modal abierto'));
modal.addEventListener('sb-ui-modal-close', () => console.log('Modal cerrado'));
