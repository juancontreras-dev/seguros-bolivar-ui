Radio Button

Componente de selección única (single choice) con estados completos (default, hover, focus, disabled, error), tamaños (small, medium, large) y variantes para formularios y casos de uso reales. Compatible con todas las marcas del design system.

Estados Básicos

1. Default

2. Hover

Pasa el mouse sobre los radio buttons

3. Focus

Click o usa Tab para ver el focus

4. Disabled

5. Error

Borde rojo indica validación fallida

Ejemplo de uso HTML 
<!-- Estado Default -->
<label class="sb-ui-radio">
  <input type="radio" class="sb-ui-radio__input" name="example" />
  <span class="sb-ui-radio__circle"></span>
  <span class="sb-ui-radio__label">Opción 1</span>
</label>

<!-- Estado Selected -->
<label class="sb-ui-radio">
  <input type="radio" class="sb-ui-radio__input" name="example" checked />
  <span class="sb-ui-radio__circle"></span>
  <span class="sb-ui-radio__label">Opción 2</span>
</label>

<!-- Estado Error -->
<label class="sb-ui-radio sb-ui-radio--error">
  <input type="radio" class="sb-ui-radio__input" name="example" />
  <span class="sb-ui-radio__circle"></span>
  <span class="sb-ui-radio__label">Campo requerido</span>
</label>
