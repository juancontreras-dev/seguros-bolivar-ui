Dropdown

Componente de menú desplegable para opciones y acciones contextuales. Compatible con todas las marcas del design system.

Ejemplo Básico

Click en el botón para ver el menú desplegable
Ejemplo de uso HTML 
<!-- Dropdown con Web Component -->
<sb-ui-dropdown>
  <button slot="trigger" class="sb-ui-button sb-ui-button--primary">
    Opciones
  </button>
  <div slot="content">
    <button class="sb-ui-dropdown__item">Editar</button>
    <button class="sb-ui-dropdown__item">Eliminar</button>
  </div>
</sb-ui-dropdown>
