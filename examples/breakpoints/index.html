Breakpoints (Puntos de Quiebre)

Los breakpoints son los anchos de pantalla donde el diseño cambia de comportamiento. El sistema usa 6 breakpoints con enfoque mobile-first: diseña para móvil primero y agrega cambios solo cuando sea necesario para pantallas más grandes.

Breakpoints disponibles

Cada breakpoint define un ancho mínimo de pantalla. Los estilos que se aplican en un breakpoint también aplican en todos los más grandes. Por ejemplo, un estilo en md también funciona en lg, xl y xxl.

Nombre Abreviatura Min-width (px) Min-width (rem) Descripción Casos de Uso
XS Extra Small xs 0 0rem Mobile por defecto Teléfonos pequeños (240-375px)
SM Small sm 576 36rem Tablets pequeñas Teléfonos grandes (576-767px)
MD Medium md 768 48rem Tablets Tablets y pantallas medianas (768-991px)
LG Large lg 992 62rem Desktop pequeño Laptops y desktops (992-1199px)
XL Extra Large xl 1200 75rem Desktop estándar Desktops y pantallas grandes (1200-1399px)
XXL Extra Extra Large xxl 1400 87.5rem Desktop grande Monitores 4K y ultrawide (1400px+)

Cómo usarlos en la librería

No necesitas escribir media queries. Solo agrega el sufijo del breakpoint a la clase y la librería se encarga del resto. Sin sufijo = mobile por defecto.

Guía práctica por breakpoint

Valores y estrategias recomendadas para cada tamaño. Úsalo como referencia rápida al organizar tu layout.

XS - Mobile (0-575px)

Todo apilado en una sola columna. Es el punto de partida del sistema.

  • Grid: 1 columna (sb-ui-col-12)
  • Gap: 0.5-1rem
  • Padding: 1rem
  • Font: 0.875rem

SM - Teléfono Grande (576-767px)

Pantalla un poco más ancha. Aumenta el espaciado pero generalmente sigue siendo una columna.

  • Grid: 1 columna (sb-ui-col-sm-12)
  • Gap: 1-1.5rem
  • Padding: 1.5rem
  • Font: 1rem

MD - Tablet (768-991px)

El primer breakpoint donde tiene sentido dividir en 2 columnas. Ideal para contenido lado a lado.

  • Grid: 2 columnas (sb-ui-col-md-6)
  • Gap: 1.5rem
  • Padding: 1.5rem
  • Font: 1rem

LG - Desktop Pequeño (992-1199px)

Ya hay espacio para 3 columnas. El layout de desktop empieza a tomar forma aquí.

  • Grid: 3 columnas (sb-ui-col-lg-4)
  • Gap: 1.5-2rem
  • Padding: 2rem
  • Font: 1rem

XL - Desktop (1200-1399px)

Desktop estándar. El contenedor limita su ancho a 1140px para mantener buena legibilidad.

  • Grid: 3-4 columnas (sb-ui-col-xl-3)
  • Gap: 2rem
  • Padding: 2rem
  • Font: 1rem

XXL - 4K/Ultrawide (1400px+)

Pantallas grandes. Aumenta el ancho máximo del contenedor a 1320px para aprovechar el espacio.

  • Grid: 4-6 columnas (sb-ui-col-xxl-2)
  • Gap: 2-3rem
  • Padding: 2rem
  • Font: 1rem
