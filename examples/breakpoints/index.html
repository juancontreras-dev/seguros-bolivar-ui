Breakpoints (Puntos de Quiebre)

Sistema de 6 breakpoints responsive del Design System. Mobile-first: xs (default), sm (576px), md (768px), lg (992px), xl (1200px), xxl (1400px). Todos los componentes de layout soportan estos breakpoints para crear interfaces adaptables a cualquier pantalla.

Sistema de Breakpoints Completo

Seis puntos de quiebre que definen cómo responde el diseño a diferentes tamaños de pantalla. Mobile-first: comienza en mobile y expande.

Nombre Abreviatura Min-width (px) Min-width (rem) Descripción Casos de Uso
XS Extra Small xs 0 0rem Mobile por defecto Teléfonos pequeños (240-375px)
SM Small sm 576 36rem Tablets pequeñas Teléfonos grandes (576-767px)
MD Medium md 768 48rem Tablets Tablets y pantallas medianas (768-991px)
LG Large lg 992 62rem Desktop pequeño Laptops y desktops (992-1199px)
XL Extra Large xl 1200 75rem Desktop estándar Desktops y pantallas grandes (1200-1399px)
XXL Extra Extra Large xxl 1400 87.5rem Desktop grande Monitores 4K y ultrawide (1400px+)

Sintaxis de Media Queries

Cómo usar los breakpoints en CSS. El sistema es mobile-first: define estilos base para móvil, luego amplía con media queries.

Mobile-first approach (recomendado) CSS 
/* Estilos base (XS: mobile) */
.container {
  grid-template-columns: 1fr;
  font-size: 0.875rem;
  padding: 1rem;
}

/* SM: 576px+ (teléfonos grandes) */
@media (min-width: 576px) {
  .container {
    padding: 1.5rem;
  }
}

/* MD: 768px+ (tablets) */
@media (min-width: 768px) {
  .container {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* LG: 992px+ (desktop pequeño) */
@media (min-width: 992px) {
  .container {
    grid-template-columns: repeat(3, 1fr);
    font-size: 1rem;
  }
}

/* XL: 1200px+ (desktop) */
@media (min-width: 1200px) {
  .container {
    max-width: 1140px;
  }
}

/* XXL: 1400px+ (4K/ultrawide) */
@media (min-width: 1400px) {
  .container {
    max-width: 1320px;
  }
}
Con clases responsive (utilities) HTML 
<!-- Usar sufijos de breakpoint en clases -->
<div class="sb-ui-grid sb-ui-grid-cols-1 sb-ui-grid-cols-md-2 sb-ui-grid-cols-lg-3">
  <!-- 1 columna mobile, 2 tablets, 3 desktop -->
</div>

<!-- Gap responsive -->
<div class="sb-ui-gap-1 sb-ui-gap-md-3 sb-ui-gap-lg-5">
  <!-- 4px mobile, 16px tablet, 48px desktop -->
</div>

<!-- Orden responsive -->
<div class="sb-ui-col-order-2 sb-ui-col-order-md-1">
  <!-- 2º mobile, 1º tablet en adelante -->
</div>

Guía de Uso por Breakpoint

Recomendaciones de diseño y layout para cada breakpoint del sistema.

XS - Mobile (0-575px)

  • Grid: 1 columna
  • Gap: 0.5-1rem
  • Padding: 1rem
  • Font: Pequeño (0.875rem)

SM - Teléfono Grande (576-767px)

  • Grid: 1-2 columnas
  • Gap: 1-1.5rem
  • Padding: 1.5rem
  • Font: Normal

MD - Tablet (768-991px)

  • Grid: 2-3 columnas
  • Gap: 1.5-2rem
  • Padding: 1.5rem
  • Font: Normal

LG - Desktop Pequeño (992-1199px)

  • Grid: 3-4 columnas
  • Gap: 2rem
  • Padding: 2rem
  • Font: Grande (1rem)

XL - Desktop (1200-1399px)

  • Grid: 4+ columnas
  • Gap: 2-3rem
  • Padding: 2rem
  • Font: Grande

XXL - 4K/Ultrawide (1400px+)

  • Grid: 5+ columnas
  • Gap: 3rem
  • Padding: 2-3rem
  • Font: Muy grande
