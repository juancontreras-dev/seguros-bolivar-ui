Tipografía

Clases utilitarias de tipografía del Design System. Usa sb-ui-heading-* para títulos, sb-ui-text-* para textos, y combínalas con modificadores de color (sb-ui-text--primary) y peso (sb-ui-text--bold) sin escribir CSS adicional.

Títulos (Headings)

Usa las clases sb-ui-heading-h1 a sb-ui-heading-h6 para aplicar la escala tipográfica del sistema. El tamaño y peso provienen de los tokens de la marca activa.

Textos (Body, Label, Caption)

Clases para texto de contenido, etiquetas de formulario, notas auxiliares y texto de botones.

sb-ui-text-body — 1rem, regular

Texto de cuerpo estándar para párrafos y contenido principal.

sb-ui-text-label — 0.875rem, semibold

Etiqueta de formulario

sb-ui-text-caption — 0.75rem

Texto auxiliar o nota al pie

sb-ui-text-button — 1rem, medium

Texto para botones
Ejemplo de uso
HTML 
<p class="sb-ui-text-body">Párrafo de contenido principal</p>
<label class="sb-ui-text-label">Nombre completo</label>
<span class="sb-ui-text-caption">Última actualización: enero 2026</span>
<span class="sb-ui-text-button">Guardar cambios</span>

Pesos de fuente (Font Weight)

Modificadores de peso para ajustar la jerarquía visual. Combínalos con cualquier clase base.

sb-ui-text--light (300)

Textos decorativos o subtítulos suaves

sb-ui-text--regular (400)

Texto de cuerpo por defecto

sb-ui-text--medium (500)

Énfasis moderado, botones

sb-ui-text--semibold (600)

Labels y subtítulos

sb-ui-text--bold (700)

Headings y énfasis fuerte

Ejemplo de uso
HTML 
<p class="sb-ui-text-body sb-ui-text--light">Texto light</p>
<p class="sb-ui-text-body sb-ui-text--regular">Texto regular</p>
<p class="sb-ui-text-body sb-ui-text--medium">Texto medium</p>
<p class="sb-ui-text-body sb-ui-text--semibold">Texto semibold</p>
<p class="sb-ui-text-body sb-ui-text--bold">Texto bold</p>

Combinaciones

Las clases son composables: combina tamaño + color + peso para obtener el estilo deseado en una sola línea de HTML.

Heading + color + peso

h2 + primary + bold

H2 Primary Bold

h3 + secondary + medium

H3 Secondary Medium

h4 + error + semibold

H4 Error Semibold

Texto + color + peso

body + primary + medium

Body Primary Medium

label + secondary + bold

Label Secondary Bold

caption + muted + regular

Caption Muted Regular
Ejemplo de uso
HTML 
<!-- Heading con color y peso -->
<h2 class="sb-ui-heading-h2 sb-ui-text--primary sb-ui-text--bold">
  Título destacado
</h2>

<!-- Body con color secundario -->
<p class="sb-ui-text-body sb-ui-text--secondary sb-ui-text--medium">
  Descripción relevante
</p>

<!-- Label con color muted -->
<span class="sb-ui-text-label sb-ui-text--muted">
  Información auxiliar
</span>
