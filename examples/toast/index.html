Toast

Notificaciones flotantes tipo toast construidas como Web Component con Lit. Soporta 4 tipos (success, info, warning, error), 6 posiciones, auto-dismiss con barra de progreso, y gestión de múltiples instancias vía ToastManager.

Tipos de notificación

Cuatro tipos de toast según el contexto del mensaje.

Success

Operación completada correctamente.

Ejemplo de uso - Success
HTML + JS 
<!-- Con link y script ya en el head, showSuccess ya está disponible en window -->
<button onclick="showSuccess('Los cambios se guardaron correctamente.', { title: 'Guardado exitoso', autoDismiss: 4000 })">
  Ver Success
</button>

Info

Información relevante para el usuario.

Ejemplo de uso - Info
HTML + JS 
<!-- Con link y script ya en el head, showInfo ya está disponible en window -->
<button onclick="showInfo('Hay una nueva versión disponible.', { title: 'Información', autoDismiss: 4000 })">
  Ver Info
</button>

Warning

Advertencia que requiere atención.

Ejemplo de uso - Warning

Posiciones

El toast puede aparecer en 6 posiciones de la pantalla.

Ejemplo de uso - Posiciones
JS 
showToast({ type: 'info', message: 'Mensaje', position: 'top-left',    autoDismiss: 3000 });
showToast({ type: 'info', message: 'Mensaje', position: 'top-right',   autoDismiss: 3000 });
showToast({ type: 'info', message: 'Mensaje', position: 'top-center',  autoDismiss: 3000 });
showToast({ type: 'info', message: 'Mensaje', position: 'bottom-left', autoDismiss: 3000 });
showToast({ type: 'info', message: 'Mensaje', position: 'bottom-right',autoDismiss: 3000 });
showToast({ type: 'info', message: 'Mensaje', position: 'bottom-center',autoDismiss: 3000 });

Auto-dismiss y barra de progreso

El toast puede cerrarse automáticamente tras N milisegundos. La barra de progreso visual muestra el tiempo restante.

Sin auto-dismiss

Permanece hasta que el usuario lo cierre manualmente.

2 segundos

Se cierra automáticamente tras 2s.

5 segundos + progress bar

Muestra barra de progreso mientras cuenta el tiempo.

10 segundos + progress bar

10 segundos con barra de progreso visible.

Ejemplo de uso - Auto-dismiss
JS 
// Sin auto-dismiss (permanente hasta que el usuario lo cierre)
showToast({ type: 'info', title: 'Persistente', message: 'Ciérralo con el botón X.' });

// Con auto-dismiss (ms)
showToast({ type: 'success', message: 'Desaparece en 2s', autoDismiss: 2000 });

// Con auto-dismiss + barra de progreso
showToast({
  type: 'warning',
  title: 'Atención',
  message: 'Desaparece en 5s',
  autoDismiss: 5000,
  showProgress: true
});

Gestión de múltiples toasts

El ToastManager apila automáticamente los toasts. Puedes ocultar o eliminar todos los activos con las funciones globales.

Control de toasts

Toasts activos: 0
Ejemplo de uso - Gestión múltiple
JS 
import {
  showToast, showSuccess, showInfo, showWarning, showError,
  hideAllToasts, removeAllToasts, ToastManager
} from 'https://juancontreras-dev.github.io/seguros-bolivar-ui/dist/sb-ui-components.min.js';

// Crear varios toasts
showSuccess('Archivo guardado');
showInfo('Tienes 3 mensajes nuevos');
showWarning('Espacio en disco bajo');
showError('Error al subir imagen');

// Gestión programática
hideAllToasts();   // Oculta todos (con animación)
removeAllToasts(); // Elimina todos del DOM

// Usar el ToastManager directamente
const manager = ToastManager.getInstance();
const id = manager.show({ type: 'info', message: 'Hola' });
manager.hide(id);   // Ocultar por ID
manager.remove(id); // Eliminar por ID

Uso como elemento HTML

También puedes colocar <sb-ui-toast> directamente en el HTML y controlarlo con JavaScript.

Elemento declarativo en HTML

El elemento <sb-ui-toast> está en el DOM. Llama a show() / hide() con JavaScript.

Ejemplo de uso - Elemento HTML
HTML 
<sb-ui-toast
  id="mi-toast"
  type="success"
  title="Acción completada"
  message="El formulario se envió correctamente."
  position="top-right"
  auto-dismiss="5000"
  show-progress
></sb-ui-toast>

<script>
  const toast = document.getElementById('mi-toast');
  toast.show();   // Mostrar
  toast.hide();   // Ocultar
  toast.toggle(); // Alternar

  // Escuchar eventos
  toast.addEventListener('sb-ui-toast-show', () => console.log('Mostrado'));
  toast.addEventListener('sb-ui-toast-hide', () => console.log('Ocultado'));
  toast.addEventListener('sb-ui-toast-click', () => console.log('Clic'));
</script>

API del componente

Propiedades / Atributos 
// Atributos HTML del elemento <sb-ui-toast>
type         = 'info' | 'success' | 'warning' | 'error'  // default: 'info'
position     = 'top-right' | 'top-left' | 'top-center'
             | 'bottom-right' | 'bottom-left' | 'bottom-center'  // default: 'top-right'
size         = 'small' | 'medium' | 'large'              // default: 'medium'
title        = string                                    // Título del toast
message      = string                                    // Mensaje del toast
auto-dismiss = number (ms)                               // 0 = no auto-dismiss
show-close   = boolean                                   // default: true
show-progress= boolean                                   // default: false
visible      = boolean (reflejado)                       // default: false

// Métodos JavaScript
toast.show()              // Muestra el toast
toast.hide()              // Oculta el toast
toast.toggle()            // Alterna visibilidad
toast.pauseAutoDismiss()  // Pausa el timer
toast.resumeAutoDismiss() // Reanuda el timer

// Eventos (bubbles: true, composed: true)
sb-ui-toast-show   // Al mostrarse
sb-ui-toast-hide   // Al ocultarse
sb-ui-toast-click  // Al hacer clic
Opciones de showToast() 
import { showToast, showSuccess, showInfo, showWarning, showError } from 'https://juancontreras-dev.github.io/seguros-bolivar-ui/dist/sb-ui-components.min.js';

showToast({
  type: 'success',          // 'info' | 'success' | 'warning' | 'error'
  title: 'Título',          // opcional
  message: 'Mensaje',       // texto del toast
  position: 'top-right',    // posición en pantalla
  size: 'medium',           // 'small' | 'medium' | 'large'
  autoDismiss: 4000,        // ms (0 = no auto-dismiss)
  showClose: true,          // mostrar botón X
  showProgress: false,      // mostrar barra de progreso
  clickable: true           // emitir evento al hacer clic
});

// Atajos por tipo:
showSuccess('Mensaje', { title: 'OK', autoDismiss: 3000 });
showInfo('Mensaje');
showWarning('Mensaje', { autoDismiss: 5000, showProgress: true });
showError('Mensaje', { title: 'Error' });
