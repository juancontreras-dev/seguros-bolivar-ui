Stepper

Componente de indicador de progreso paso a paso (stepper) para guiar usuarios a través de procesos multi-paso. Soporta 3 tipos (números, iconos, mix), 2 orientaciones (horizontal, vertical) y múltiples estados.

Stepper Funcional

Usa los botones o haz clic en un paso completado para navegar. El paso actual y los completados se actualizan automáticamente.

Cómo hacerlo funcional (JavaScript) JS 
// Actualizar estado visual del stepper
function updateStepper(container, currentStep) {
  const steps = container.querySelectorAll('.sb-ui-stepper__step[data-step]');
  steps.forEach(function(stepEl) {
    const stepNum = parseInt(stepEl.getAttribute('data-step'), 10);
    stepEl.classList.remove('sb-ui-stepper__step--filled-default', 'sb-ui-stepper__step--empty-active');
    const circle = stepEl.querySelector('.sb-ui-stepper__step-circle');
    if (stepNum < currentStep) {
      stepEl.classList.add('sb-ui-stepper__step--filled-default');
      circle.innerHTML = '<i class="fa-solid fa-check"></i>';
    } else if (stepNum === currentStep) {
      stepEl.classList.add('sb-ui-stepper__step--empty-active');
      circle.textContent = stepNum;
    } else {
      circle.textContent = stepNum;
    }
  });
  container.setAttribute('data-current-step', currentStep);
}

// Botones y clic en pasos
var stepper = document.getElementById('stepper-demo-1');
var current = 1;
updateStepper(stepper, current);
document.getElementById('stepper-next').onclick = function() {
  if (current < 4) { current++; updateStepper(stepper, current); }
};
document.getElementById('stepper-prev').onclick = function() {
  if (current > 1) { current--; updateStepper(stepper, current); }
};
stepper.querySelectorAll('.sb-ui-stepper__step-circle').forEach(function(btn) {
  btn.addEventListener('click', function() {
    var step = parseInt(btn.closest('.sb-ui-stepper__step').getAttribute('data-step'), 10);
    if (step <= current + 1) { current = step; updateStepper(stepper, current); }
  });
});

Guía de Clases BEM

Estructura de Clases

Clase Descripción
.sb-ui-stepper Contenedor principal del stepper
.sb-ui-stepper--horizontal Orientación horizontal (default)
.sb-ui-stepper--vertical Orientación vertical
.sb-ui-stepper--type-icon Tipo icono (62px)
.sb-ui-stepper--type-mix Tipo mixto: icono + badge numérico
.sb-ui-stepper--track-dash Track punteado (verdes sólidas tras completados)
.sb-ui-stepper__step Paso individual (empty default - pendiente)
.sb-ui-stepper__step--empty-active Paso activo sin completar (amarillo)
.sb-ui-stepper__step--filled-default Paso completado (verde)
.sb-ui-stepper__step--filled-active Completado + seleccionado (verde borde oscuro)
.sb-ui-stepper__step--clickable Paso clickable con hover effects
.sb-ui-stepper__step--disabled Paso deshabilitado (opacity 0.5)
.sb-ui-stepper__step-circle Círculo del paso
.sb-ui-stepper__step-circle-badge Badge numérico (solo en type-mix)
.sb-ui-stepper__step-label Etiqueta descriptiva
.sb-ui-stepper__step-track Línea conectora (siempre verde)
