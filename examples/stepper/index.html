Stepper

Componente de indicador de progreso paso a paso (stepper) para guiar usuarios a través de procesos multi-paso. Compatible con todas las marcas del design system.

Ejemplo Básico

Información Personal Datos de Contacto Confirmación
Ejemplo de uso HTML 
<!-- Stepper con Web Component -->
<sb-ui-stepper current-step="2">
  <sb-ui-step step="1" status="completed">Paso 1</sb-ui-step>
  <sb-ui-step step="2" status="active">Paso 2</sb-ui-step>
  <sb-ui-step step="3" status="pending">Paso 3</sb-ui-step>
</sb-ui-stepper>
