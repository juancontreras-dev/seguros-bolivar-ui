Tag Component

Etiquetas visuales para estados y categorización

Componente Tag con 32 variantes: 4 colores (Error, Warning, Success, Info) × 2 tamaños (Large, Small) × 2 esquinas (Off, Rounded) × 2 estados de icono (con/sin icono izquierdo).

Error (Rojo)

Tag con fondo rojo (#dc3545) y texto blanco para indicar errores, fallos o estados críticos que requieren atención inmediata.

Error Large + Off + Icono
Error Large + On + Icono
Error Small + Off + Icono
Error Small + On + Icono
Error Large + Off
Error Large + On
Error Small + Off
Error Small + On

Ejemplo de uso

HTML 
<!-- Tag Error - Large con icono -->
<span class="sb-ui-tag sb-ui-tag--error">
  <i class="fa-solid fa-circle-exclamation"></i>
  Error
</span>

<!-- Tag Error - Small sin icono -->
<span class="sb-ui-tag sb-ui-tag--error sb-ui-tag--small">
  Error
</span>

<!-- Tag Error - Large Rounded -->
<span class="sb-ui-tag sb-ui-tag--error sb-ui-tag--rounded">
  <i class="fa-solid fa-circle-exclamation"></i>
  Error
</span>
